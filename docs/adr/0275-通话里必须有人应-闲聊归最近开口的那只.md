# ADR-0275：通话里必须有人应——闲聊归最近开口的那只，只有一只时不问分类器

- 状态：已采纳（2026-09-09）
- Issue：#1183（承 #1163 / ADR-0271、#1153 / ADR-0270）
- 维护者拍板：没人对口时**最近开口的那只**接（否掉「一律管理员」）

## 背景

ADR-0272 之后真机第二次用：进通话、管理员打完招呼，说「我说话你能听到吗？」——沉默；换成
「我要管理员，我说话，你能听到吗？」才有人答。VPS 日志（seq 72 / 73）：前一句落成裸
`chat_message`，后一句才是 `user_message{mentions:[admin], dispatch:"auto"}`。

病根不在识别、不在 TTS，在派活分类器的口径：ADR-0270 明写「闲聊 / 问候 / 确认不是活 →
none，群里没人接」——那是 #1153 里维护者给**文字群聊**定的，对的。语音里这条口径错了：打电话
对面不应答，在用户眼里与「坏了」没有区别（同 ADR-0272 对「接通了一直沉默」的判断）。第一句
「你能听到吗」正是确认，被判成 none 整场沉默；第二句碰巧带了「管理员」三个字才被分到它头上。

## 决策

### 1. 通话里 `none` / `failed` 都落到「最近开口的那只」

`say()` 的派活分支多一个判据 `inCall`（通话进行中、通话名单非空、名单没降级）。分类器回
`none`（闲聊）或 `failed`（网关 / 超时 / 认不出）时，通话里不再留空：派给 `callAnswerer` ——
`lastSpeakerAmong(尾段日志, 通话成员)`（最后一条有正文的 `assistant_message` 的那只，只要了工具
没说话的不算），一只都没开过口时退回 `dispatchFallbackOf(通话成员)`（管理员在通话里就是它，
否则通话第一只）。落下来的仍是同一条 `user_message{mentions, dispatch:"auto"}`——不新增事件
类型、帧不变、协议不进位。

「最近开口的那只」是维护者选的：像真对话，回应的是刚说完话的那个；否掉「一律管理员」——多只
在场时每句闲聊都由管理员应，其他几只像不在。

通话里 `failed` **不再落**「这句话没派出去」那条系统话：那句话的理由是「不说人会干等」，通话里有人
应了就没有人在等。分类没成功仍在 daemon 日志里有痕迹（`requestDispatch` 的 log）。`skipped`
（所有者没订阅）照旧回落改动前的行为、不出声——那个团队一只都起不了 turn，通话本身就起不来。

### 2. 通话里只有一只时不问分类器

一只在场，分类的答案只可能是它或 none，而 none 在通话里又落回它——这一次网关往返（真机
0.5～2 秒，且消息要等它判完才落盘、才出现在时间线上）什么都决定不了。直接落
`picked:[它]`，`dispatch:"auto"` 记号照带（不是人点的名）。这是人说完到 agent 开口之间最贵的
几段之一，#1184 的第一刀。多只在场照问：活要派给对口的那只，「谁刚向人提了问题」那条规则还在。

### 3. 通话块提示词加一句「像打电话」

`renderVoiceCallPrompt` 尾句从「短句、口语」改成「像打电话：先说结论，一两句就停，对方要细节再
展开」。回复要经 TTS 读出来，长篇就是让人对着听筒干等——模型时间与合成时间都跟着长度走。

## 没有通话时一个字不变

`inCall` 为假的每条路与 ADR-0270 逐字相同：none 只落 `chat_message`，failed 落一句「没派出去」，
mention:true 回落名单第一只。回归用例钉在 `tests/runtime/sessionService.test.ts`「通话里必须有人应」
最后一条。

## 否掉的候选

- **改分类器提示词让它在通话里不回 none**：分类器仍可能回 none / failed，服务端还是得兜；两处
  各写一遍口径迟早分家。留给服务端一处判。
- **一律管理员**：见决策 1。
- **通话里所有成员都接**：一句「好的」三只齐答，三倍的钱与三段语音排队。

## 代价与已知未做

- 通话里一句真正的闲聊也会起一轮模型调用（文字群聊里不会）——这是「必须有人应」的价钱。
- 「最近开口」只读派活尾段窗口（`DISPATCH_TAIL_WINDOW`，200 条事件）；超出就退回管理员。
- **runtime 要重新部署才生效**（#791）。

## 推翻前提

- 维护者觉得通话里的闲聊被答得太勤：把 none 那条改回留空、只保留 failed 的兜底与「只有一只
  不问」——决策 2、3 不动。
