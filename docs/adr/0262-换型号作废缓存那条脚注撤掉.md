# ADR-0262：模型选择器底下「换模型会作废 N 已缓存 token」那条脚注撤掉

- 状态：已接受
- 日期：2026-09-08
- 关联：#1095 / #434（这条脚注当初的来处，已关闭、没有 ADR）/ ADR-0260（界面上「不能据此行动」的那几格撤掉）/ ADR-0254（上下文浮层给订阅用户把钱整段删掉）/ ADR-0248（订阅用户不许自带 key）/ ADR-0249 · ADR-0250 · ADR-0214（撤一处界面时死代码一起删）

## 背景

维护者对着真机点的：

> 里面的文案"换模型会作废 5.2K 已缓存 token，下一轮全价重算。"去掉

这一行来自 #434（「换型号会让缓存清零，但界面上一个字都没说」），当时的理由写在代码注释里，是站得住的：

> 不做成确认弹窗 —— 换型号是每天要做很多次的动作，拦一道等于天天罚站；这里只把数字摆在眼前，值不值由人自己判断。

## 诊断

那句「值不值由人自己判断」有一个前提：**读的人手上有一把尺子，能把「5.2K token 全价重算」换算成一个他在乎的量。** #434 那天这把尺子是有的 —— 每个人都在烧自己的 key，浮层与页脚上到处是钱。

两条后来的决定把这把尺子拿走了：

- **ADR-0248**：订阅用户不许自带 key。他们付的是月费，「全价」花的是额度，不是账单上的一笔。
- **ADR-0254**：这枚触发器的浮层里，钱**整段删掉**了。

于是这一行落进了 ADR-0260 那道判据的射程 —— **用户能不能据此做点什么**：

| | |
|---|---|
| 说了什么 | 换型号要重算 5.2K token 的缓存 |
| 能据此做什么 | 换与不换，答案和这个数字无关 —— 要换是因为这一款不合适，而这一格恰恰是他专门点开来换型号的 |

「值不值」需要两边都有数，而这个浮层如今只报得出左边那半。**报一个换不出结论的量，就是在这一列每天扫很多遍的地方常驻一行噪音**，同 ADR-0249 撤掉 Auto 第二行正文时那笔账：论证没错，代价估小了。

## 决策

### 1. 撤的是这一格，不是这件事

「换型号作废缓存」仍然是真的，缓存仍然按型号存。撤掉的只是**决定之前**那句提醒；**事后**那本账还在 —— `CostPanel` 的 `cache 命中 X%（A/B）` 一行不动。

两者不是一件事的两处：那一行报的是已经发生的命中率（同 ADR-0260 决定 3「页脚报的是已经发生的事」），这一条报的是一个还没发生、且这个浮层已经不再用同一种单位说话的代价。

**没有做替身**：不换成「换型号这一轮会多花一点」那类不带数的说法 —— 它仍然在回答同一个问题，只是把唯一能让人判断的那一半也丢了（同 ADR-0254 砍掉「本会话用掉 5 小时额度的 1.3%」那次）。

### 2. 死代码一起删，动机写在这里

脚注是这四样的唯一消费方，一起清（同 ADR-0249 删 `ModelMenuItem.vision`：留着跑不到的数据，下一个人会以为它还在被谁读）：

- `ModelPicker` 的 `cachedTokens` prop 与本地那份 `fmtTokens`
- `App.tsx` 唯一那处 `cachedTokens={cachedTokensNow(events)}`
- `src/shared/contextEstimate.ts` 的 `cachedTokensNow`
- `tests/shared/cachedTokensNow.test.ts` 与 `tests/e2e/modelSwitchCacheHint.e2e.ts`

**删测试的动机按 ADR-0020 写明**：这两份测试跟着它们测的产品代码在同一个 PR 里消失，属 L2 常规开发 —— 不是「删了求变绿」（删之前门禁本来就是绿的，删之后 497 文件 6160 用例仍全绿）。

### 3. `tests/e2e/fakeModel.ts` 的 `cachedTokens` 开关**留着**

它此刻确实没有消费方，但它与上面四样不同类：那是**假服务器的一个旋钮**，照的是真上游 API 的字段（DeepSeek 方言 `prompt_cache_hit_tokens`，issue #213 的「API 不报 ≠ 命中 0」），不是产品里没人读的数据。旋钮的职责就是被将来的用例拧，留着不会让人误以为「有谁正在读它」。

## 代价

- **换型号作废缓存这件事，决定之前界面上从此一个字都不说。** 真会撞上的那条路径没有别的话接着 —— 一个自带 key、正靠缓存省钱的用户，换一次型号会安静地多花一轮全价。翻回去的路是一次 revert：这一行的判据（`cachedTokens >= 1000`）与取数（`cachedTokensNow`）都在这次 diff 里。
- `contextEstimate.ts` 从此不再有人问「此刻缓存了多少」这个问题；下一个需要它的人要重写那六行（连同「这只是上一次账单说的，不是服务端此刻的真实状态」那条注意事项 —— 它写在被删掉的那段文档注释里，这里存一份指针）。
