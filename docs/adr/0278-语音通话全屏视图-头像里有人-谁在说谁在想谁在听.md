# ADR-0278：语音通话全屏视图——头像里有人，谁在说、谁在想、谁在听

- 状态：已采纳（2026-09-09）
- Issue：#1185（承 #1163 / ADR-0271、#1184 / ADR-0277）
- 维护者原话：「语音通话中点开可以以全屏弹窗的方式显示语音状况，上面的人物头像也要显示人类自己」
  「把整个语音聊天质感做得真实一点」

## 背景

ADR-0271 的通话栏是一条 30px 的浮条：几只 agent 的小头像、在说的那只亮一圈。真机上它把「通话」
画成了一个开关，而不是一个正在发生的场面——谁在想、谁在听、我说的话它听到没有，都看不出来；
头像里没有人，通话像是几只 agent 之间的事。

## 决策

### 1. 点通话栏展开一屏（app 窗口内全屏），栏留着

`VoiceCallOverlay`：Radix Dialog 铺满 `inset-0`，深色，正中一排头像（agent 按名单顺序在前，人在后），
顶上一句状态、底下两行字幕、控制条四颗（加人 / 麦 / 静音 / 结束）与通话栏是**同一批回调**——两处
不许各有一套语义。收起 / Esc 关掉视图，通话本身照旧；通话结束视图跟着消失。栏的左半整块可点
（一条栏上「点开看看」是最自然的手势）+ 右边一颗带名字的「全屏」钮。

### 2. 头像里的人：发起人 + 自己，不画别的成员

**人类「谁在听」不落盘**（ADR-0271 已知代价：加入是本机动作）。能确定在场的只有两个：这一场的
发起人（`voice_call_changed` 的 byUid，`callStarterUid` 取 `sinceSeq` 那条）与自己。别的成员点没点
「加入」这台机器不知道——画一个可能根本没在听的人是撒谎的勾（#722）。发起人就是自己时只画一格。
要画全得把人类的加入也落成事件（帧 + 协议进位 + runtime），留到真有多人同时在听的团队再做。

### 3. 每格一个状态词，判据全是已有的事实

- agent：播放器在读它 = **在说话**（外圈亮 + 呼吸）；`openTurns` 里还欠回答 = **在想…**；其余 **在听**。
- 自己：麦克风能量门说有声 = **在说话**（外圈按 `mic.level` 撑开，ADR-0277 的 `level` 事件）；
  开着麦 = **在听**；没加入 / 关麦 = **没在听**（半透明）。
- 顶上那句按优先级取一条：在说 > 在想 > 你在说话 > 在听你说 > 你还没加入 > 麦克风关了。

字幕：agent 正在读的那句原文（播放器的 `text`，ADR-0277 加的）+ 你正在说的这句（识别快照）。
两行定高，有没有话都占着位，控制条不跳。

判据抽成纯函数（`voiceCallView.ts`：`callTiles` / `callStatusText` / `callStarterUid`）——通话栏与
全屏两处画同一份事实，各写一遍迟早分家（同 voiceCall.ts 的纪律）。

## 否掉的候选

- **系统级全屏 / 独立窗口**：多一个窗口的生命周期要管（关会话、换账号、退出），而这一屏只是
  会话页的一个视图。
- **给 agent 的头像画真实声浪**：播放走 Web Audio，接一个 AnalyserNode 就有；但这一轮先用
  「在说 = 亮环呼吸」，真机看过再决定值不值一条 rAF 循环。
- **入场 / 挂断音效**：合成一段音一行代码的事，但「像不像真的」不靠这个，先不加。

## 代价与已知未做

- 别的成员看不见（决策 2）。
- agent 那格的外圈不随它的音量动，只呼吸。
- 状态词「在想…」来自 `openTurns`（欠回答），模型真正开始出字之前与之后都算「在想」——没有
  区分「排队中」与「正在写」。
- 真机一次没跑过；渲染层要发版。
