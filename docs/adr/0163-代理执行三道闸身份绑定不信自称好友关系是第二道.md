# ADR-0163：代理执行的三道闸——身份按绑定的算不按自称的，好友关系是第二道

- 状态：已接受
- 日期：2026-08-28
- 关联：issue #665；ADR-0151（好友代理宪法，决策 1 的后半句在这里落地）；
  ADR-0162（握手层的信任根——本决策是它在**应用层**的同一条推理）

## 背景

ADR-0162 把握手层堵上了：只有拿着邀请码那把一次性 secret 的人才建得起连接。
但那之后，A 侧执行器仍然按**帧里自称的 `fromUid`** 去查白名单：

```ts
const grant = deps.getGrants().find((g) => g.friendUid === req.fromUid) ?? null;
```

`getGrants()` 回的是**全部**好友的授权。于是一个被正常邀请、已 pin 的好友 B，
把 `fromUid` 填成另一个好友 C 的 uid，就吃到 C 那份白名单。A 授权过两个人以上即成立。

这与 ADR-0162 修的那个洞是**同一类错误的第二面**：
握手层认了「哪把密钥」，应用层却把「你是谁」交还给对方自己填。

同时，ADR-0151 决策 1 写着「查 friendships（关系还在吗）+ 本地白名单，
friendships 被删除 = 代理权限跟着死」——全链路 grep 不到任何 friendship 判断。
删好友不收回代理权，只有手动点「撤销」才断。

## 决策

A 侧执行器在**白名单之前**加两道闸，顺序固定：

1. **身份闸**：`req.fromUid` 必须等于**这条通道绑定的那个好友**（`friendUid`——
   A 发邀请时定的，握手时由 secret 证明钉死）。对不上就拒。
   过闸之后，**查授权与记审计一律按绑定的那个 uid**，自称的那个只用来核对，
   永远不进查询。这一条是「B 不能自选身份」的落点。
2. **关系闸**：那个好友现在还是不是好友。名单从 `FriendsManager` 注入。
3. 白名单（原有）。

顺序有意：身份对不上时，「你们不是好友」这句话说的是**哪个人**都讲不清。

### 名单是三态的：`readonly string[] | null`

`null` = 还没同步好（没登录 / 首次快照还没到），**一律按拒处理**——
名单未知时放行等于这道闸不存在。但拒的话说不同的人话：「过一会儿再试」
和「你们已经不是好友了」对 B 是两件事，前者该等，后者别等。

**不能拿空数组冒充「还不知道」**：那等于把「所有人都不是好友」写死进冷启动窗口。
`FriendsManager.acceptedFriendUids()` 因此显式回 `null`，登出时退回 `null` 而不是 `[]`。

### 新鲜度 = 用户在界面上看到的那份

名单缓存挂在**每一份新鲜快照**上（`cacheAccepted`）：Realtime 推、
degraded 轮询兜底、渲染层 `list()` 拉，三条路都喂到它。
不另起一条拉取——两份名单迟早不一样。

### grant 帧也过关系闸

已经不是好友时，握手后推**空清单**（协议里 `servers: []` 就是「撤销全部授权」）。
不这么做的话，删了好友之后对面仍然看得见 A 接了哪些服务、每个服务有哪些工具——
调不动，但看得见，而那份清单本身就是不该给的东西。

## 后果

| | |
|---|---|
| ✅ | 冒充另一个好友的请求被拒，且**审计记的是绑定的那个身份**（台账要能当证据用，自称的字段谁都能填；冒充这件事本身进 `denyReason`） |
| ✅ | 删好友 = 代理权限当场跟着死，不必再想起来去点一次「撤销」 |
| ✅ | 三个依赖都是**必填**（`friendUid` / `friendUids`），加一个调用点就必须想一遍这两道闸——可选的安全字段是给人忘的 |
| ⚠️ | 冷启动那一小段窗口（登录到首次好友快照之间）代理调用会被拒。自愈：B 重试即可。宁可拒也不能在名单未知时放行 |
| ⚠️ | 关系闸的新鲜度就是好友快照的新鲜度：Realtime 掉了且轮询没起来时，名单会陈旧。取舍是「与用户看到的一致」，而不是每笔调用打一次库 |

## 被否掉的路

- **删好友时自动清掉存储里的授权**：会让「误删好友再加回来」变成授权静默消失。
  闸放在使用点是可逆的——加回好友就恢复。台账留着，用户仍可主动撤销。
- **忽略 `req.fromUid`、悄悄用绑定的那个**：能防提权，但冒充这件事就查不出来了。
  显式拒 + 记审计，A 才看得见「有人试过」。
- **每笔调用查一次 friendships 表**：一次工具调用一次数据库往返，
  而白名单内本来就是全自动的高频路径；换来的新鲜度提升不值这个代价。
