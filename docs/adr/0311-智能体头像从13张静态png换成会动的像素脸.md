# ADR-0311：智能体头像从 13 张静态 png 换成会动的像素脸

- 状态：已接受
- 日期：2026-09-21
- 关联：#1345（本条）、#1307（渲染层的法理来源）、#1282（状态的数据源，未做）、#971 / #1007 / #1013（坑位派生 / 手动挑 / 编辑页那一格）、ADR-0250（queued 不画打字指示器）、ADR-0264 / ADR-0286（名册里查不到的不给脸）

## 背景

`assets/agent-avatars/01–13.png` 是 13 张 128px 的静态像素人像，`fnv1a(agentId) % 13`
派生坑位（#971），用户也可以手动挑一个存进 `workspace_agents.avatar_slot`（#1007）。
#1345 要把它们换成会动的形象。

`Blocked by: #1307`，而 **#1307 在仓里一行代码都没有**（维护者自己在 #1345 的评论里
写了这句）。它的产出物散在两处：一套法理写在 #1307 的正文里，一份能跑的原型画在
`claude/auto-mobile-app-redesign-0a1e2f` 分支的 `.demo/mobile-agents-redesign.html`
里。本条把那份原型搬进 `src/`，于是 #1307 要的「渲染层」有了它需要的那一片；
#1307 自己还欠的是 15 个状态到 `agentPhase` / `sessionOrb` / `backgroundRuns` 的适配层，
以及接进花名册——后者卡在 #1282 的数据源上。

## 决策

### 1. 坑位数和顺序都不动，仍然是 13：一个坑位对一个角色

`fnv1a(agentId) % 13` 已经落库。改 13 就是**给所有没手动挑过头像的 agent 换一张脸**，
连手动挑过的 `avatar_slot` 也会指到另一个人身上。所以 `AGENT_AVATAR_COUNT` 一个字不动，
`ADMIN_AVATAR_SLOT = 6` 也不动，13 个角色包与 01–13.png 一一对上——**谁的脸都不换，
只是从静态画变成会动的**。

否决了「接受一次性重排、在界面上说明白头像换过一批」：已经手动挑过的人会莫名其妙换脸，
而那正是 `avatar_slot` 这一列存在的意义。

### 2. `agentAvatarSrc` 的返回值不是「坑位号」而是一个三选一的联合类型

这一格的答案本来就有三种，一个 `string` 表达不了：内置像素脸（agent）/ 一张真图
（人的 `profiles.avatar_url`）/ 什么都查不到。原来的编码是「空串 = 不给脸」——把第三种
挤进第二种的取值里。换成 `AvatarRef = FaceAvatar | {kind:"image"} | null` 之后，tsc 会
当场指出每一个没分清的地方。

`agentFace` / `agentFaceIfKnown` 回的是**收窄过的** `FaceAvatar`，不是整个联合：它们
结构上只可能是脸，回联合就得让每个调用点再判一次一个永远不成立的分支。

「名册里查不到就不给脸」这条纪律仓里重复了六遍（ADR-0264 用量表 / ADR-0286 通话那一行 /
选人名单 / 群名单变更那一行…），这次收进 `agentFaceIfKnown` 一个函数里。

### 3. 动不动**由状态自己说**，不另给一个开关

`faceAnimates(state)` 从状态表推导。名册与各种选人弹层传 `plain`，于是它们**由构造**
就是静止的一帧——不靠每个调用点记得传 `animate={false}`。两份判据迟早分家，而分家的
形态是安静的：要么一张该动的脸僵着，要么一墙本该静止的脸开始呼吸。

会动的只有「此刻正在看的那只」：私聊头部（`dmFaceState`）与通话里那几格
（`VoiceCallBar` / `VoiceCallOverlay` 的 `TILE_FACE`）。名册那一墙、@ 选人弹层、
头像选择器那 13 格一律静止——十三个 rAF 同时跑只是噪音，而一墙脸同时呼吸本身就是噪音。

### 4. `plain` 是「我们不知道」，不是「空闲」

名册那一栏今天查不到谁在跑（那张表里没有这一格，#1282），画一枚恒灰的「空闲」角标等于
宣称一件我们查不到的事——#722 那颗撒谎的勾。所以 `plain` 不画角标、也不动，是第 16 档，
与 15 个真状态并列。

同理 `dmFaceState` 在「一条都不欠」时回 `plain` 不回 `idle`：「它没在答我」说不了
「它闲着」（它可能正在别的群里跑）。

### 5. 深色底不描边，靠盘底

圆盘固定纸白 `#f2f2f3`，**两个主题一样**。纯黑头发压在纯黑底上会整个糊成一团，而盘底
把这件事解决在脸自己这一层，不用宿主按背景传一个描边色进来（#1307 第三个待定项的答案，
取自维护者在 #1345 评论里给的那一版）。代价：深色界面上一墙脸是一墙亮白的圆点，比原来
那 13 张 png 更显眼——那 13 张的底本来也是白的，所以这不是新增的代价，只是没被改掉。

### 6. 原型里的 `#` 必须挑一个值（它是个真 bug）

原型的取色是 `FC[c] || c`，而 `FC` 里没有 `'#'` 这个键，于是 `fillStyle = '#'`——非法
颜色值，canvas 规范要求**忽略这次赋值**，那一格因此用的是上一格的颜色，画出来取决于
遍历顺序。在 20px 的原型上看不出来。产品里取 `L`（已有的浅灰）并显式写成 `O`（轮廓），
于是白脸在纸白盘底上有一圈说得清的边，调色板还是四色。

### 7. 眼镜重画：只留镜框下沿 + 镜腿 + 鼻梁

原型画的是完整的 4×4 方框，而眼睛本身就是 2×2、**正好占满框的内腔**——画出来是一坨
实心黑，读作墨镜/眼罩；只留上下两道也不行，两侧的杠会在鼻梁处连起来横贯整张脸，成了
一条蒙眼带（两版都在真浏览器里画出来看过）。这个分辨率上装不下「边框 + 里面还看得见
眼睛」，所以只留镜框下沿这个最容易认的特征。

顺带守住了那条硬法理：**会动的只有眉眼嘴**。方框会把眯眼 / 闭眼 / 左右看 / 叉叉全盖掉，
那两只戴眼镜的水獭就再也没有表情了。

### 8. 纯函数与 canvas 分家，不是洁癖

jsdom 没有 `getContext()`。判断留在 canvas 那一侧等于**那部分零执行覆盖**，而这一族的
失败全是安静的：一行画料少一个字符、两个角色包描成一样、某一档状态忘了不动——屏幕上
都只是「脸有点怪」，不报错、不塌、门禁全绿。所以 `composeFrame` 是纯函数（回网格坐标），
`paint.ts` 只把网格换成像素、一个判断都不做。

`tests/helpers/setup.ts` 显式把 `getContext` 桩成 `null`：**把「jsdom 画不了」这件事
说出口**，而不是让每条渲染用例各自忍受二十来行「Not implemented」的噪音——真正的失败
会被埋进去。断言脸画出来没有，判据是 DOM 上的 `canvas[data-face]`。

### 9. 13 张 png 删掉

不引用的资源就是死资源（同 ADR-0249 / ADR-0250 删死代码那条）。要回看去 git 历史——
角色包正是照着它们描的。

### 10. `scripts/build-face-gallery.mjs`

这套形象**在 app 里看不全**：名册一律 `plain`，会动的只有正开着的那条私聊头部与通话里
那几格，而一个表情要凑齐条件才出得来（限流 / 冻结 / 出错各要一次真事故）。没有这一页，
改一格眉毛只能靠想象。产物是自包含的 html（esbuild 把真的 `lib/ottoFace/` 内联进去），
**不进门禁**——判据在 `tests/renderer/ottoFace/`，这一页只是让人看一眼。

## 代价与已知未做

1. **真机一次没跑过**。看过的是 `.demo/face-gallery.html` 在浏览器里画出来的样子，不是
   app 里的样子。
2. **花名册上没有状态**，一律 `plain`——数据源卡在 #1282（决策 4 的理由）。#1307 要的
   15 个状态到 `agentPhase` / `sessionOrb` / `backgroundRuns` 的适配层也没做，今天只有
   私聊头部那一条 `dmFaceState` 和通话那张 `TILE_FACE`。
3. **群聊头部那一摞一律 `plain`**：那里同时有好几只，一枚角标答不了「谁在忙」。
4. **`prefers-reduced-motion` 与 `devicePixelRatio` 都是 effect 跑的那一下读的**，不订阅
   变化。前者同 `ui/nav-stack.tsx` 的取舍；后者的表现更值得记一笔——把窗口从 Retina 拖到
   外接屏（或反过来）时，画布的后备分辨率还是旧的那一档，**像素画会糊**，要等这一格因为
   别的原因重绘才恢复。真要治得挂一个 `matchMedia("(resolution: Xdppx)")` 的监听。
5. **深色界面上一墙亮白圆点**（决策 5）。
6. **几何没写成断言**（盘径 15.8 格、角标半径 0.15、锚点那几个数）：那是一组在真浏览器
   里量出来的构图值，扫源码的正则会在任何无害重构上翻红（同 ADR-0236 第 1 条）。保鲜期
   在紧挨它们的注释里。
7. **13 个角色互不相同有断言，「像不像原来那张 png」没有**：01/04/10/12 对应的是哪一个
   ottoFace 角色，#1345 正文说「没核实」，这一版沿用原型按长相描的那一份。
8. **手机端不在射程内**（`mobile/` 今天不画智能体头像，#1345 正文已经核过）。
