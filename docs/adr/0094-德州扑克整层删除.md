# ADR-0094: 德州扑克整层删除

日期：2026-08-25
状态：已接受（stanyan 会话指示，issue #415）

## 决定

德州扑克从"藏起来"改为"删掉"。ADR-0085 第 3 条把这一层留在原地、只关掉
`POKER_ENABLED` 开关；本 ADR 推翻那半条决定，代码与数据一并移除：

- **网关**：`services/gateway/src/poker/`、`pokerApi.ts`、`pokerStore.ts`、
  `tables.ts`、`checks/twoseat.mjs`，以及 `gateway.ts` 的 `/v1/poker` 路由和
  `server.ts` 的牌桌装配。`supabaseRpc.ts` 里只服务牌桌的 `Rest` / `createRest` /
  `asBoolean` 随之删除。
- **主进程与桥**：`src/main/pokerApi.ts`、8 个 poker IPC handler、shellBridge 的
  `Poker*` 类型与十条 CHANNELS、preload 接线。
- **牌局邀请**：整条一起走 —— 它是"约你上哪张桌"，桌没了就没有指向。含
  `game_invites` 表、四个 invite bridge 方法、`GameInvite` 类型、
  `NotificationTarget` 的 `invite` 分支、好友区和 DM 面板里的"约打牌"。
- **渲染层**：`PokerTable.tsx`、`InviteTableMenu.tsx`、`GameInviteToast.tsx`、
  `lib/pokerSeat.ts`、`lib/splitFlap.ts`，以及 store 里的牌桌 state/action。
- **主区档位**：`SessionMode` 的 work / game 两档随之取消。只剩一档就不再是
  档位，Work/Game 分段控件、game 档下的 `TableList` 与 `WorkStatusList` 一起删。
- **DB**（`supabase/migrations/0011`）：表 `poker_tables` / `poker_hands` /
  `poker_stacks` / `poker_transfers` / `game_invites`，RPC `poker_buyin` /
  `poker_cashout` / `poker_join` / `poker_leave` / `poker_settle` / `rebuild_stack`，
  及其 RLS 策略。
- `src/shared/features.ts` 的 `POKER_ENABLED` 开关本身。

## 不动的东西

token 钱包（`token_wallets` / `token_ledger` / `token_balances`，
`grant_tokens` / `spend_tokens` / `rebuild_balance`，`OFFICIAL_GRANT_ENABLED`）
属于"官方赠额"这条**独立**的线（ADR-0085 第 1、2 条），同样休眠，但不是德州。
`token_ledger` 里 `reason = poker_buyin / poker_cashout` 的历史行也保留：
账本是历史，余额由它累加而来，删了余额就错了。

`gsap` 依赖保留 —— ADR-0029 已经把它的用途扩到了 worktree 药丸，不再是牌桌专属。

## 理由

- ADR-0085 的判断是"翻回来 = 掰开关"，所以留着。三个月的事实是没有翻回来的
  打算：筹码就是官方额度 token（ADR-0022），而官方停供 token 是产品转向，
  不是临时限流。一个不会翻回来的开关，成本不是零 —— 它让 shellBridge 多十条
  channel、store 多九个 action、`mode !== "game"` 散在四处，每个读代码的人都
  得先弄清这些是不是活的。
- 恒假的开关比删除更容易骗人：它读作"关着的功能"，实际是"不存在的功能"。
- DB 侧不删则更糟：五张表带着 RLS 策略挂在库里，下一个审 RLS 暴露面的人得
  逐条判断它们还算不算数。

## 被本 ADR 调整的既有决定

- **ADR-0085 第 3 条**：从"UI 隐藏、后端保留"改为"整层删除"。第 1、2 条
  （注册赠额归零、模型全自配）不动。其"恢复清单"的第 1、3 项作废。
- **ADR-0022 / 0023 / 0024 / 0082**（德州系）：决定本身是历史记录不改，
  但它们描述的东西在代码里不再存在。
- **ADR-0027**：好友推送兜底那一半仍然有效；牌局邀请那一半随本 ADR 失效。

## 会被推翻的前提

「官方不供 token」若因商业化重新成立，德州是否恢复仍是**独立**决定
（ADR-0085 已经这么写过）。真要恢复，成本不再是掰开关，而是从 git 历史里
把这一层捞回来重接一遍 —— 本 ADR 接受这个代价。
