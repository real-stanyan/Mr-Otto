# ADR-0192：模型目录跟随上游，下线的 id 直接删掉

- 状态：已接受
- 日期：2026-08-30
- 相关：issue #768、ADR-0031（thinking 方言从目录查）、ADR-0009 追记（目录维护能力表）

## 背景

`src/shared/modelCatalog.ts` 上一次成批更新是 2026-08-24（价目表的抄表日期）。六天后重新对了一遍各家，
28 条里至少 8 条指向已经下线或改名的型号：

- `grok-4` / `grok-4-fast`：xAI 2026 年把这两个 id 重定向到了 `grok-4.3`
- `kimi-k2-0905-preview` / `moonshot-v1-128k`：月之暗面 **2026-08-31 全平台下线**（也就是这次改动的第二天）
- `gpt-5` / `gpt-5-mini` / `gpt-4.1`：在售旗舰已经是 GPT-5.6 三档
- `gemini-2.5-pro` / `gemini-2.5-flash`：落后到 Gemini 3.x
- `pixtral-large-latest`：不在 Mistral 的型号页上了
- `Qwen/Qwen3-235B-A22B`：硅基流动已下架
- `MiniMax-M2` → `MiniMax-M3`；`qwen3-max` / `qwen-plus` / `qwen-vl-max` → Qwen3.8 那一代

另有一批不是"id 错了"而是"数错了"：Claude 三条的 `contextWindow` 写着 200_000，实际 Opus 5 / Sonnet 5
都是 1M；`claude-haiku-4-5-20251001` 那个日期后缀本身就是多余的（Claude 的型号 id 是完整的，补后缀会 404）。

这类腐烂**不报错**。用户在下拉框里看到「Grok 4」，点下去拿到一个 400；上下文圆环按 200K 报占用，
而真实窗口是它的五倍，于是自动压缩会在离阈值还很远的地方触发。目录是"开箱能选"的默认集合，
它的错法全都是安静的。

## 决策

**一、目录跟随上游：上游下线/改名的 id 直接从目录删掉，不保留。**

不做「新旧都留、旧的标注（已下线）」：菜单里一半的项点了就是 400，而用户分不出哪个还活着——
一个点不通的选项比没有这个选项更糟。旧日志不受影响：`resolveModel` 本来就有目录外兜底
（chip 退化成显示原始 id、查不到价就不显示钱数），而"日志永远可重放"靠的是这条兜底，不是靠目录里留着尸体。
目录顶上那句「不是白名单」这次真的用上了。

**二、每家维持 2–3 款的形状**（旗舰 + 便宜/视觉），不借上游换代的机会扩成大杂烩。
唯一的例外是智谱：给到四款，因为 app 三个出厂默认里有两个住在这一家
（后台小模型 = `glm-4.7-flash`、看图代读员 = `glm-4.6v-flash`）。

**三、能打真接口的就打，不能打的标注出处。**
本机有 key 的三家用实况定稿：DeepSeek / GLM / Kimi Code 各打了一次 `GET /v1/models`，
GLM 的六个候选 id 还逐个发了一次真 `chat/completions`（智谱的 `/v1/models` 只回付费文本款，
免费档和视觉款一条都不在里面——只信它会把 `glm-4.7-flash` 误判成不存在）。
其余各家取官方文档页，方言（thinking）沿用原有结论，推断来的在注释里写明是推断。

顺带记下一条实证：Anthropic 那三行的 `thinking` 留空原先写的是"手上没有 key 验不了"，
现在有出处了——官方 OpenAI 兼容层**明确不支持** extended thinking（连同 PDF / citations / prompt caching），
所以那个字段不是"不敢发"，是"这条路上没有这个开关"。

**四、`DEFAULT_HELPER_MODEL` 从 `glm-4.5-flash` 换到 `glm-4.7-flash`。**
同样免费、窗口 128K → 200K；换的直接原因是 4.5-flash 已经不在目录里了，而
**默认值落在目录外是一种静默故障**：`createCheapAdapter` 查不到型号直接返回 `null`，
三个 turn 外挂（分区分类 / 跟进建议 / 微压缩）集体失效，界面上一个字都不会说。
看图代读员的默认保持 `glm-4.6v-flash` 不变——`glm-5.3-flash`（1M、原生视觉、$0.15/$0.50）
各方面都更好，但把出厂默认从免费档换成付费档是另一件事，不该搭这趟车顺手改掉。

## 后果

- 新增一条护栏断言（`tests/shared/modelCatalog.test.ts`）：三个出厂默认必须在目录里查得到，
  看图那个还得 `supportsVision === true`。这是这次差点踩空的那一格——删型号的手不会去看默认指向哪儿。
  已按变异验证过：把默认改回 `glm-4.5-flash` 时它变红。
- 价目表整体重抄（抄表日期改 2026-08-30）。促销价一律取**促销结束后的标准价**
  （Gemini 3.7 Flash、GLM-5.3 Flash 都在促销期内），与原有的「错峰价取高峰档」同一条理由：
  页脚那个数是"这一次大概花了多少"，报低了会让人以为便宜一半。
- 查不到确切现价的四款（`kimi-k2.7-code` / `qwen3.8-flash` / `llama-3.3-70b-versatile` /
  `deepseek-ai/DeepSeek-V4-Pro`）在价目表里留空 = 不显示 cost，不是显示 0。
- MiniMax 的 `baseUrl` 从 `api.minimax.chat` 改成 `api.minimaxi.com`：前者是上一代域名，
  与目录里早就填着的 console 地址（platform.minimaxi.com）本来就不是一套。
- 存量用户手动选过的型号如果这次被删了，`normaliseHelperModel` / `normaliseVisionModel`
  会把它退回默认；正在跑的会话里那款则走 `resolveModel` 兜底，不会崩，但下一次真调用会拿到上游的错。
  这是"直接删"这个选择的已知代价，接受。
- 这份目录**还会再腐烂**。这条 ADR 不解决腐烂，只把腐烂时的处置定下来：删、标日期、能打就打真接口。
