# ADR-0260：本地时间线撤掉「请求信封已更新」那一行

- 状态：已接受
- 日期：2026-09-08
- 关联：#1091 / #383（请求信封落盘）/ ADR-0235 ③（云会话把它藏起来）/ ADR-0250（云会话连折叠行也撤掉）/ #929（两份名单对表）/ ADR-0219（`PRIVACY_VERDICTS`）

## 背景

维护者对着 dev 里的时间线说：

> 「请求信封已更新：deepseek-v4-flash · 思考 on · 工具 17 把」这个文本信息不用显示了

`request_envelope`（#383）每次模型调用前落一条，去重规则是「信封与上一条不同才落」。典型会话整场只有一两条——但**它的比较键里有工具清单和思考挡位**：接一台 MCP、启用一个 skill、动一次思考开关，都会让下一圈冒出新的一行。真机上这条会话就是这么攒出多行的。

## 诊断

这一格的判据在 ADR-0235 ③ 已经立过一次，原话是「这条事件说的是群里发生的事，还是机器的内务」——当时给 `request_envelope` 的答案是内务，云会话里藏掉。

本地时间线是同一个问题。同一个问题在两条时间线上给两个答案，不是「本地更详细」，是没人回来重判过：ADR-0235 那次的动机是「云会话该长得像一条会话」，改的是云那侧，本地这侧顺手没动。

更锋利的判据是**用户能不能据此行动**——`isAuditEvent` 放行的那批里，每一条都过得了这一关：

- `model_changed`：之后的话由谁说，换回去是一个动作
- `branch_checked_out`：这段话是在哪份代码上说的
- `session_shared`：`@好友` 那条正文不进模型，这一行是那个动作唯一的痕迹
- `route_changed`：钱从谁账上出变了

而「工具从 16 把变成 17 把」没有对应的动作。它是给维护者调参用的一行，而调参的人本来就该去轨迹视图。

## 决策

### 1. 落盘照旧，只撤那一行

`request_envelope` 仍然落、仍然去重、仍然是「这次请求由什么拼出来」的唯一凭据。`sessionPackage` 的隐私闸（`PRIVACY_VERDICTS` 里它是 `strip`，烤着 system prompt 全文）也要它继续存在——**撤的是投影不是事实**，同本仓一贯的分工。

### 2. 两处一起改，`isAuditEvent` 写显式 `return false`

`toThreadMessages.isAuditEvent` 与 `Timeline.EventRow` 是同一件事的两份名单（`tests/renderer/timelineLists.test.ts` 对表）。`isAuditEvent` 那边**不是**删掉 case 落进 `default`，而是显式列出来写一句为什么——同一个文件里 `section_classified` / `session_topic_assigned` / `checkpoint_created` 都是这么写的，理由也一样：落 default 得到的是同一个答案，但那是「碰巧对」，`default` 的语义哪天变了这条没人会注意到。

### 3. 断言钉的是决定，不是实现

新增的两条（`tests/renderer/toThreadMessages.test.ts`）里，第一条是「投不出任何消息」，第二条是「夹在两句话中间不留白行」。

对表那条（timelineLists）管的是两份名单一致——**两处一起把它加回放行名单，那条照样绿**。所以这里另钉一条：这条事件不上聊天区，是一个决定。

### 4. 调参的人去轨迹视图

`replay/trajectory.ts` 的 `default` 分支照旧把它画成一行 system 行（summary 就是事件类型名）。没有为此专门做展示——需要看信封全文的人本来就在读日志或轨迹，而**为了一个维护者场景在每个人的对话里常驻一行**正是这条 issue 要修的东西。

## 代价与已知未做

1. **轨迹视图里那行是光秃秃的 `request_envelope`**（走 `systemSummary` 的兜底），型号/思考挡位/工具数得点开才看得到。没顺手给它写一条 summary：那是另一个页面的活，而这条 issue 的主语是聊天区。
2. **换了思考挡位、接了一台 MCP，界面上从此没有任何提示**。这两件事各自有自己的入口（设置页、MCP 面板），信封那一行本来就不是它们的通知渠道——但确实是曾经唯一会说出口的地方。
3. 存量日志里的那些 `request_envelope` 不会消失，只是不再画出来——重放旧会话与新会话看到的是同一个样子（投影改了，日志没动）。
