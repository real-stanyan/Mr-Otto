# ADR-0165：代理调用的取消是「通知对方停手」，不是「当作没发生」——取消照样记审计

- 状态：已接受
- 日期：2026-08-28
- 关联：issue #668；ADR-0151（§4「AbortSignal 转成取消帧」、防线 1「什么参数，分享者可查」）；
  ADR-0164（执行侧三道闸）

## 背景

ADR-0151 §4 写了「AbortSignal 转成取消帧」，实现只做了一半：

- B 侧 `proxyMcp` 的 abort 只在本地 `reject`，**不发帧**；
- A 侧 `proxyHost` 明确注释「不处理 proxy_cancel」，`callTool` 也没传 signal。

于是 **B 以为取消了，A 那边照跑到底** —— 用的还是 A 自己的凭证。
写工具（下单、退款）尤其要紧：B 的界面说「已取消」，A 的账号里单已经下了。

同时，A 侧还留着 `src/main/proxyExecutor.ts` —— `proxyHost` 的旧双胞胎，
全仓只有它自己的测试引用它，而它带着 ADR-0164 刚修掉的那一行
（`grantOf(req.fromUid)`：按自称的身份查授权）。它是唯一处理了取消帧的模块，
也正因为如此看起来「更完整」，谁接上就退回 #665 之前。

## 决策

### 1. 取消是一条要真的发出去的帧

- B 侧：`abort` **和超时**都先发 `proxy_cancel` 再 reject。两者是同一件事的两种起因
  ——「B 不等了」；不通知的话，A 会为一个没人接的结果继续动自己的账号。
  发不出去也照样 reject（通道断了正是「不必再等」的另一种情形）。
- A 侧：每笔在跑的调用登记 `reqId → AbortController`，收到 `proxy_cancel` 就 abort，
  signal 一路传到 `mcpHub.callTool` → 连接层，SDK 那边才真的停得下来。
  认不出的 `reqId` 静默忽略 —— 迟到的取消不是错误。
- 通道断开（`startProxyHost` 的退订）同样 abort 所有在跑的：它们占着 A 的凭证在动
  A 的账号，而下命令的那个人已经不在线上了。

### 2. **取消照样记审计**，而且说清「可能已经动过」

取消帧到达时，工具可能已经把单下了 —— HTTP 请求发出去之后 abort 掉的是**等待**，
不是**副作用**。所以取消不回结果帧（B 早就不等了），但**一定记账**：
`outcome: "error"`，原因写「B 中途取消——A 这边可能已经动过了」。

抹掉这一笔，等于让审计账在最需要它的那一次（写操作被中途叫停）恰好是空的。

### 3. 审计账里的参数要看得见

ADR-0151 防线 1 点名要「谁、何时、哪个工具、**什么参数**、什么结果」。
`argsSummary` 一直存着，但桥的类型把它丢了、UI 也没显示 —— 那条防线只做了三分之二。
现在它过桥、进 `auditLine`、在记录行下面单起一行显示（`{}` / `null` 不占行）。

### 4. 删掉 `proxyExecutor.ts`

`proxyHost` 是唯一的执行路径。留着一份**没有三道闸、还处理了取消**的旧副本，
下一个人接哪一份全靠运气。它多出来的那点东西（取消）已经并进 `proxyHost`，
所以删的是纯负债，不是删功能。它的测试跟着删——测试跟着它测的产品代码走。

## 后果

| | |
|---|---|
| ✅ | B 点取消，A 真的停手；超时同理 |
| ✅ | 「取消了但可能已生效」这件事**在账上**，而不是靠用户事后去 Shopify 后台核对 |
| ✅ | 执行路径只剩一条，不会有人接错 |
| ⚠️ | 取消能不能真停下来，取决于那台 MCP server 认不认 `AbortSignal`。停不下来时审计里那句「可能已经动过」就是全部的补救——所以那句话不是免责声明，是产品的一部分 |
| ⚠️ | `argsSummary` 是截断到 200 字符的 JSON。长参数看不全，取舍在 `proxyStore`（审计要可查，但不复制整份参数） |

## 被否掉的路

- **取消就当没发生过（不记审计）**：账面干净，代价是写操作被中途叫停这件事查无实据。
- **A 侧收到取消后回一帧 `proxy_res ok:false`**：B 发 cancel 时就删了 pending，回过去必然被丢弃；
  多一条无人接收的帧只会让线上多一种要解释的情形。
- **保留 `proxyExecutor` 并给它补上三道闸**：两份实现要同步维护三道闸，
  而这正是这次要消灭的那种「谁接哪份靠运气」。
