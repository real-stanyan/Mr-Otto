# ADR-0179：`@好友` 那条正文不发给模型，但分享本身要在日志里留痕

- 状态：已接受
- 日期：2026-08-29
- 相关：issue #705（本决策）、#611（@好友 分享第一期）、#694 / ADR-0177（分享连带借出服务）、ADR-0093（`branch_checked_out` 同族的 log-only 标记事件）

## 背景

`src/renderer/src/App.tsx` 的 `submit()` 里，`@好友` 那个分支的注释写着
「分享成功才把留言发给模型」，而代码从来没有 `dispatch` 过——分享成功只 `setInput("")`
然后 `return`。注释与代码说的是两件事，谁对没人定过。

这不是「改注释还是改代码」的机械选择：它是一个产品口径，而 #694 之后这条路上还多了
一件有后果的事（同一次分享可能连带借出 Shopify 的操作权），口径没定就更不能拖。

## 决策

### 1. 正文**不**发给模型（代码是对的，注释说反了）

`@好友` 是**发送侧的一个动作信号**，与 `$skill` / `/指令` 同族，不是给模型的话。

判决性的理由不是「哪个更合理」，是另一条会出事：

> 「@小明 帮我把这批订单退了」——如果照样 dispatch，本地这只水獭会去做你**刚刚才委托
> 出去**的同一件事。两只水獭同时动同一个 Shopify，不是多余，是有害。

这条在 #694 之后更硬：B 那边用的是**你的**凭证（代理执行发生在 A 的机器上），所以
「两边同时动」指的是同一份真实数据，不是两份各自的沙箱。

### 2. 但分享必须在日志里留一行：新增 `session_shared` 事件

口径 1 的代价是这条消息**什么痕迹都不留**：输入框一清，时间线上一片空白，看起来像
消息被吞了。而分享是一件对外的、有后果的事——现在还可能连带把 MCP 服务借出去。
「谁在什么时候把这条会话连同哪几台服务给了谁」，在这之前**没有任何地方答得出**。

于是加一个 log-only 标记事件，与 `branch_checked_out`（ADR-0093）严格同族：

- 主进程在 `shareSessionToFriend` **成功之后**追加 + 推给渲染层（`src/main/index.ts`）。
  失败不记——记一条没发生的事比不记更坏。
- `ignorable: true`：模型不消费，旧版本跳过它照常重放。
- 时间线上是一行 `Marker`（`data-testid="share-marker"`），用 AUDIT 那种缩进小字而不是
  分隔线：它记的是「我把这条会话交出去了」，不是「线之下换了个世界」，量纲比切分支小一档。
- 只记好友的**显示名**不记 uid：时间线要的是人读的那个，而昵称会变——日志是历史记录，
  记的就该是当时那个名字。要按人查请走好友代理的审计账（ADR-0151 防线 1）。

**为什么是日志不是渲染层自己记一笔**：硬规则——append-only 事件日志是唯一事实来源，
任何投影必须可从日志推导。刷新即失忆的东西不配叫事实。

### 3. `session_shared` 进隐私闸

发给 B 的包里剥掉它（`PRIVACY_STRIP_TYPES`）。留着等于顺手告诉 B
「我还把这个给了小红，而且把 Shopify 借给了她」——发送方的**社交关系**与**授权史**，
两样都不是 B 该看的。它本来也只是发送方时间线上的一行，对接收方没有任何用处。

## 被否掉的路

- **照注释改代码，分享完照样 dispatch**——否决，理由见决定 1。
  「@小明 你看看这个」这种也一样：本地水獭收到「你看看这个」，没有对象、没有动作，
  只会开始瞎猜。
- **不加事件，改成渲染层在时间线上塞一条本地消息**——否决。刷新就没，而分享的后果不会
  跟着一起没（对方手里那份包还在，借出去的服务还连着）。这正是硬规则要挡的那种「事实」。
- **事件里记 friendUid**——否决。今天没有任何一处需要它（时间线显示名字，按人查走审计账），
  而它一旦进了日志就会被分享包带出去，多一道要记得剥的东西。

## 后果

| 面 | 结果 |
|---|---|
| 用户 | `@好友` 之后时间线上多一行「已分享给小明：…（连带借出 shopify）」，不再像消息被吞了 |
| 模型 | 视野不变——这条事件不进 `deriveMessages`，`@好友` 的正文照旧不进上下文 |
| 接收方 B | 看不到这一行（隐私闸剥掉） |
| 旧版本 | `ignorable`，跳过照常重放 |
| 轨迹视图 | 多一行 `shared → 小明 (+shopify)` |

## 天花板

- **只在分享成功时记**。分享失败（上传/发 DM 炸了）不留痕——但 ADR-0177 那个 wart
  （失败时授权已经写进台账）仍然存在，它在「好友代理 → 已授权」里看得见。
- **不记 uid** 的代价：同名好友在时间线上分不开。要区分请看好友代理的审计账。
