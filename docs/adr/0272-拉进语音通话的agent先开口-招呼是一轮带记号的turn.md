# ADR-0272：拉进语音通话的 agent 先开口——招呼是一轮带记号的 turn

- 状态：已采纳（2026-09-09）
- Issue：#1174（承 #1163 / ADR-0271）
- 维护者拍板：拉进就打招呼（否掉桌面本地念固定一句、只加提示两条候选）

## 背景

ADR-0271 上线后维护者真机第一次用：开始语音通话 → 拉进管理员 / 开发 / 设计 → 等 → 没有任何声音
→ 结束。VPS 日志（会话 `9fa351a9`）里两次通话之间零条 `user_message`、零次模型调用、零次 TTS。
TTS 链路本身是通的（冒烟那六笔 `usage_event` 真出声）。

病根不在播放：ADR-0271 的语音只读**回复**，`voice_call_changed` 本身不起任何一轮——没 @ 也
没打字，agent 就没话可读。参考的是微信群语音，而人被拉进通话是会先开口的；现在的形态是
「接通了，对面一直沉默」，与「坏了」在用户眼里没有区别。

不 @ 也能聊这件事**不在本条范围里**——它已经由 ADR-0270 的派活承担：通话进行中，人的话没 @
任何人时按职责在通话成员里挑一只接，挑不出归管理员 / 通话第一只，回复照样被读出来。本条补的
只是「接通那一下」。

## 决策

### 1. 招呼是一轮 turn，载体是一条带 `greeting` 记号的 `user_message`

`setVoiceCall` 落下新名单之后，对**新增**的每只各落一条开场白
（`voiceCallGreetingText`，`fromUid` 是改名单的那个人，`mentions` 是它自己，`greeting: "voice_call"`）
并入队，与接力开场白同一条路（`relayAfterTurn`）：先落盘再入队，于是 `openTurns` 的重启补跑、
「排队中 / 正在回复」那盏灯、`unseenUserTail` 的不重采样全部免费拿到。**不新增事件类型**
（十一处穷举清单一处不碰），记号与 `relay` / `dispatch` 同族——只影响时间线（不画正文，
`voice_call_changed` 那一行已经说了「拉进了通话」）与判据，模型投影照普通人话读。

`isHumanOpening` 对它成立（有 mentions、没 relay）：招呼那轮若 @ 了别人，接力链首就是这条
招呼，点火的人是改名单的人——与人亲手 @ 的一句话逐字同一个形状，不用给接力链另开一种链首。

### 2. 三条进门的路只有两条打招呼

| 路 | 打不打 | 为什么 |
|---|---|---|
| 人点通话栏（开始 / 加人，`call` 帧） | 打 | 这是 issue 本身 |
| agent 调 `invite_to_call` | 打 | 被拉进来的不知道自己被拉了；拉它的那只下一句往往就要 @ 它，招呼开场白与接力开场白折进同一个 job（协调器去重），它只跑一轮 |
| 人亲手 @ 了通话外的（`say` 里的自动拉进） | **不打** | 他那句话就是开场白，再问一句「打个招呼」是同一只答两轮 |

### 3. 价钱与 say 同一侧算，被拒时名单照落、招呼不打、群里一句说清

拉进来的每只都是一次真花钱的模型调用，所以 `call` 帧递一个 turn 桶的问价回调进 `setVoiceCall`
（同 say 的 budget：数量由 `setVoiceCall` 自己算出的**新增只数**决定——帧里的名单是并集不是
增量；超容量拒绝不夹价；0 只不问）。被拒时**名单照落**（招呼不是人的动作，不该让一次限速把
名单改动整个吞掉），但**不安静地不打**——群里一条署名系统的话把原因说出口（同 ADR-0270
「派活失败群里说一声」）。`invite_to_call` 那条路不问价：拉人的是模型，它自己那一轮已经付过价，
一轮里能拉几只由工具调用次数封着。

### 4. 文案的形状

`[系统] 「X」被拉进了语音通话。X：用一两句话打个招呼——说你是谁、能帮什么，然后等对方开口。
这句话会被读出来，别用列表和记号。` 同 `relayOpeningText`：`[系统]` 开头、第三人称点名（群里
每只都读得到这条）、再用「名字：」对上被叫到的那只；名字过 `promptSafe`。

## 否掉的候选

- **桌面本地用它的音色念一句固定的「我是 X，我在」**：即时、几乎不花钱，但那不是它自己说的话，
  之后仍要打字它才回——接通的感觉有了，「活人感」没有；两套机制并存则是第二个要维护的地方。
- **只在通话栏加一句提示**：零成本，但不像打电话。
- **招呼由桌面自动发一条 say**：会在时间线上多一条伪造的人话，且每个客户端各写一遍
  （手机端还没有云会话客户端）；「谁开口」该由 runtime 决定。

## 代价与已知未做

- 每拉一只一次模型调用；首句约 6 秒才出声（LLM ≈ 3 秒 + TTS ≈ 3 秒），一次拉三只要排着说。
- 招呼那轮是普通 turn，模型可以在里面调工具；「一两句话」只靠提示词。
- 「先问再调」仍只靠提示词（ADR-0271）。
- 本机 `Timeline.tsx` 会把这条开场白画成匿名 user 气泡（#936 同族，今天走不到）。
- **runtime 与桌面渲染层都要出门才生效**：runtime 要重新部署（#791），时间线那半要发版。
- 真机一次没跑过（合并后按 #1163 的冒烟脚本补一条「开始通话后不打字就有人出声」）。

## 推翻前提

- 维护者觉得招呼吵（每次加人都有人说话）：把 `greetNewcomers` 收成只在**开始通话**那一刻打
  （`current.length === 0`），加人不打；记号、时间线、问价一个字不动。
- 招呼想不花模型钱：换成「否掉的候选」第一条，`greeting` 记号留给时间线，runtime 那半撤掉。
