# ADR-0137：右侧槽位收成一个键，后台任务面板自己掀开、且按会话记住

- 状态：已采纳
- 日期：2026-08-26
- 相关：issue #578；ADR-0109（后台任务面板的原始形态）、ADR-0031（面板只读、不进事件日志）、issue #395（前台命令跑满 30 秒自动转后台）

## 背景

右侧那块槽位（Protocol / Git Graph / 终端 / 文件 / 浏览器 / iOS 模拟器）一直是「互斥」的，但互斥只是一条**口头**规矩：六个 boolean 各存各的，每个 `open*` action 手抄一遍「把另外五个关掉」。全仓十处这样的手抄。

三件事同时压到这块地方：

1. 后台任务面板（ADR-0109）当时贴在输入框上沿。任务一多它就把正在读的对话往上顶；而且它只有「有任务才出现」这一种出现方式，用户关不掉也叫不回。
2. 后台任务的主要来源不是用户点单，是前台命令跑满 30 秒**自动**转的。用户从没点过单，却有五个任务在跑——弱信号治不了「没被告知」。
3. 切走再切回来，右侧面板一律没了：`enterChat` 把那一族开关全清成 `false`。

第 1 件要求它搬进槽位（有固定位置、有关闭键、有菜单入口），第 2 件要求它能**自己打开**，第 3 件要求槽位的状态跟着会话走。三件事都要动同一族开关，而那族开关正是十处手抄。

## 决策

**把「哪块开着」收成一个键**（`src/renderer/src/lib/sidePanel.ts`）：

- `PanelKey = "protocol" | "git" | "terminal" | "browser" | "sim" | "files" | "bg"`
- `panelFlags(key)` —— 要开这块，那一族 boolean 该是什么（全 false 再点亮一个，互斥由构造保证）
- `panelKeyOf(state)` —— 现在开着的是哪块（与渲染端那串三元**同序**）

十处手抄换成十处 `set(panelFlags(...))`。boolean 一族保留（渲染端和 store 的形状不变），但它们退化成这个键的投影。

在这个基础上：

- **后台任务成为第七块面板**（`BackgroundTasksPanel`），住进槽位，从「更多」菜单可以叫回来。
- **自动开面板**（`lib/useBackgroundWatch.ts`）：行数从 0 变成非 0 时打开，从非 0 变回 0 时关上。轮询 live 名单也搬到这一层，挂在 App 上常驻——面板关着的时候也得有人盯着，否则「有任务了」这一刻根本没人在看。
- **每会话的面板记忆**：`panelBySession: Record<sessionId, PanelKey | null>`，`enterChat(info, remembered)` 按它还原。记的位置在 App 的一个 effect 里（**结果**只有一处，而开关面板的入口有十几个）。

两条刻意的边界：

- **自动开面板只在槽位空着时发生。** 用户正看着终端/文件/Git 图的时候把他手上的东西换掉，比漏报更讨厌。代价是那种时候后台任务仍然只能靠菜单去看。
- **记忆只在内存里，不落盘。** 重启后从零开始。落盘要处理「那个会话早就删了」的清理，而收益只是重启后少点一次菜单。
- **设置页 / DM 不进记忆。** 它们和面板抢同一块屏幕，但语义不同：面板是「我在这个会话里干活的姿势」，设置页是「我刚才在别处」——切会话时前者还原、后者让位。

## 后果

- 加第八块面板只需要在 `FLAG_OF` 里加一行 + 渲染端加一条三元，不再有十处手抄可漏。漏一处的老症状（两块同时为 true、后一块静默不见）不再可能。
- 顺手修了一个既有 bug：侧栏会话行的「我在聊天视图」判据是手抄的 `!aOpen && !bOpen && …`，漏了 `filesPanelOpen`——开着文件面板时侧栏仍把那条会话画成「正在看」。现在它就是 `panelKeyOf(state) === null`。
- 面板默认看不见了。这是搬进槽位的直接代价，由自动开面板补上；如果将来发现「槽位被占时错过任务」真的疼，下一步是顶栏角标，而不是让自动开面板去抢槽位。
- `enterChat` 从「纯粹按 BootInfo 落位」变成「还要读一份记忆」。第二个参数有默认值，旧调用点和单测不受影响。

## 被否掉的路

- **把 boolean 一族直接换成单个 `sidePanel: PanelKey | null`。** 更干净，但要改渲染端和 store 的所有读点（十几处 `xxxPanelOpen`），改动面远大于收益，而且和本次三件事没有一件是必须的。收成一个键 + 保留 boolean 投影已经把「加面板要改十处」这个病根治了。
- **后台任务用顶栏角标而不是面板。** 角标是弱信号，而现在的问题正是「没被告知」——ADR-0109 已经否过一次，这次没有新证据推翻它。
- **面板记忆落 localStorage。** 见上。
