# ADR-0251：工作区设置页的「仓库」tab 重定义成「文件」——主语是工作文件夹

> 原为 ADR-0248（撞号，ADR-0074：项目 ADR 的号在合并时 claim）。提交信息里那几处 0248 改不了，靠这一行还原。

- 状态：已接受
- 日期：2026-09-07
- 关联：#1056 / 协议 10→11 / ADR-0234（这一页从云会话头部搬进设置页）/ ADR-0232（一容器一卷）/ ADR-0243（三态纪律）/ ADR-0246（起不了 turn 那一格）

## 背景

维护者对着一个奶茶店工作区（「mandy's bubble tea」）的设置页问：

> 这个页面怎么定义？并不是说所有工作区都是为了 GitHub 代码仓库而做的，也不是所有用户都是程序员

那一页当时的样子：tab 叫「仓库」，正文第一句是「水獭在这个仓库的工作副本里干活。**不是每个工作区都需要仓库**——做文案、运营这类活留空就行」，「现状」表里写着「仓库：未配仓库」，然后是一个 Git 地址框加一个 PAT 框。

ADR-0234 把这一页从云会话头部搬进设置页时，已经改过一次文案（「『不用仓库』是正当状态不是没配完」）。这次问的是更下面一层的东西：**补的是文案，没有补框架**。

## 诊断

这一页把**唯一实现出来的那种来源当成了页面本身的身份**。

真正的主语是「水獭在哪儿干活」。每个工作区都有一个共用工作文件夹——同工作区所有会话共用一容器一卷（ADR-0232）——这件事跟你是不是程序员无关。Git 仓库只是往那个文件夹里装东西的**一种方式**，而且是此前唯一做出来的一种。

三处症状是同一个病：

| 症状 | 为什么它是病 |
|---|---|
| tab 叫「仓库」 | 非程序员读到的第一个词就跟自己无关，整页被跳过——而那一页本来该告诉他「水獭给你做的东西在这儿」 |
| 正文第一句在解释「你可能用不到这一页」 | 一页要先说服你它可能与你无关，就是定义错了。自我辩护占掉了本该说事实的位置 |
| 空目录写成「未配仓库」 | 一个正当状态被写成缺一格配置。「未配」这两个字自带「还没做完」的暗示 |

## 决策

### 1. tab「仓库」→「文件」，正文里叫「工作文件夹」

tab 上是两个字（和其余六个 tab 一样宽），正文里用四个字的全称。**「工作文件夹」与本机会话那个词逐字相同**——ADR-0218 立的「云会话和本地一个开法」这次兑现到词汇上。

否掉的两个名字：

- 「工作文件夹」直接当 tab 名：最准确，但四个字会把这一行明显撑宽。
- 「资料」：对奶茶店最顺口，但罩不住代码——配了仓库的工作区打开一个叫「资料」的页面看到 git 地址，是另一头的违和。

### 2. 页面顺序倒过来：先画有什么，Git 收成下面一节

面包屑 + 清单 + 点开看在上，「从 Git 仓库带一份代码进来（可选）」在下。非程序员读到那个小标题就知道能不能跳过，**不用读完一整段解释才知道这段与自己无关**。

### 3. 「列得出内容」是改名成立的前提，不是加分项

一个叫「文件」却一个文件都列不出来的页面，是 #722「撒谎的勾」的近亲：名字承诺了一件它做不到的事。不配仓库的那半边人（文案、运营）打开这一页必须有东西可看，否则改完名还是一页空。

所以这次连着做了读帧。`probeWorkState` 早就在容器里跑 `ls -A /work`（`sandbox.ts:515`），路是铺好的。

### 4. 协议 10→11：一对 `files` / `files_result` 控制房读帧

判据同 `workspace`（ADR-0234）：**任何在籍成员都能读**。卷是整个工作区共用的一份，不是谁的私产；何况水獭做出来的东西正是群里其他人要看的那个东西。

`CsWorkNode` 五态，其中两条分界是这次的关键：

- **`absent`（容器还没建起来）与空目录是两回事。** 合成一句就会对一个刚建群的人说「你的文件夹是空的」——而那个文件夹此刻并不存在，第一次真让水獭干活时才建。
- **`binary` 单列一档。** 「读不出人话」不是失败，那是一张图、一个 zip；界面该画的是名字和大小，不是一屏乱码。

文件内容上限 `CS_WORK_FILE_MAX_BYTES = 64 KiB`，取中继单帧上限（256 KiB）的四分之一——JSON 转义、字段名、base64 都还要占地方，「一个文件看不看得完」不该是贴着上限赌出来的。超了发前半段 + `truncated: true`，界面照实说「只显示了开头一段」，**不静默截断**。

### 5. 两道路径闸缺一不可

- `normalizeWorkPath`（`src/shared/remote/workPath.ts`，三端共用）挡的是「客户端要去哪」：`..` 与绝对路径一律拒。
- 容器里的 `realpath -m` 之后必须仍在 `/work` 下，挡的是「解析完软链之后真的落在哪」。

**一条指向 `/etc` 的软链过得了第一道，过不了第二道。** 客户端那次归一化只是省一次明知会被拒的往返，不是安全边界（渲染层和主进程都不是，同 `validateRepoUrl` 的注释）。

`..` **不解释成上跳一级**：解释它意味着两条不同的输入映射到同一个地方，而那个映射里的任何一个差错都是一次容器内越界读；界面的面包屑本来就按段拼，它手上永远有目标路径的完整段列表，从不需要 `..`。同理绝对路径直接拒而不是「当成相对的」——静默换一套坐标系正好会盖住调用方的 bug。

### 6. `readWork` 刻意不走 `ensure()`

`ensure()` 会建容器、跑 clone 流程、重置 idle 计时。翻一眼文件是个**读**动作，不该有这些副作用——尤其不该让「打开设置页」触发一次可能长达十分钟的 clone。

所以 `readWork` 只认**已经存在**的那台容器：不存在 = `absent`（那意味着卷也还没有，这个工作区真的一次活都没干过），停着就起一下（exec 要求容器在跑）并照样 `markActive`——**不打点它反而永远没人扫**，`sweepIdle` 只遍历 `lastActive` 里的条目。

### 7. 新增 `FILES_BUCKET` 令牌桶

`files` 是**唯一一条会 docker exec 进容器的读帧**（`workspace` 那条只读内存里的配置）。没有闸就是「点得够快就能一直起 exec」。30 突发 / 60 每分钟：人手点目录一分钟点不到 60 次，脚本能。

`FrameHandlerDeps.readWork` 写成**必需**不是可选（同 `rateLimit` / `log` 的理由）：忘接线那天这一页会安静地永远回「读不到」，而这一层没有任何别的信号能说出「其实是没接上」。

### 8. 「读不到」不许说成「里面是空的」

同 ADR-0243 那条三态纪律。三处落地：

- runtime 读失败回 `ok: false` + 一句人话，原文只进 `deps.log`；
- 桌面客户端拿到 `ok: true` 却没有 `node` 时**当失败**，不兜底成空目录（那一路只可能是两端版本对不上）；
- 渲染层读失败时**上一份清单留在原地**，错误另起一行说——把清单清空会让人以为水獭做的东西没了。第一次就没读到时说「读不到工作文件夹」，不说「正在读取…」（后者会让人一直等）。

### 9. 起不了 turn 那一格留在这一页，挪到顶部

ADR-0246 的判据原样（只在 `blocked` 时出现），但位置从「现状」表里挪到页面顶部一整句。理由：这一页是它在云会话界面之外**唯一的落点**，删掉等于让一个没订阅的 owner 在设置页里看不到任何解释。

## 否决的路

| 路 | 为什么不 |
|---|---|
| 只改名 + 重排文案，不做读帧 | 一个叫「文件」却列不出文件的页面 = #722 撒谎的勾。名字承诺了做不到的事 |
| 顺手把「上传文件」也做了 | 中继单帧 256 KiB 上限（ADR-0167），传文件要分片或另开通道，是独立的大件。这一期不做 |
| 把 tab 藏进「高级」 | 「这个工作区该不该有文件」判不出来——奶茶店也可能有个官网仓库 |
| 起不了 turn 那一格搬进页头（跨 tab 可见） | 那才是它该住的地方，但要给设置页每次打开都加一次控制房 RPC。留给以后 |
| 解析 `..` | 见决策 5 |
| 用 `ensure()` 取容器 | 见决策 6 |

## 已知代价

1. **看得见、下载不了。** 小文件点开能看，二进制只有名字和大小，没有「保存到本机」。
2. **不能上传。** 往工作文件夹里放东西今天只有两条路：配 Git 仓库，或者让水獭自己在会话里建。这一页把这句话说出口了，但那仍然是个缺口。
3. **起不了 turn 那一格在一个讲文件的页面上是跑题的。** 见决策 9 与否决表最后一行。
4. **非 UTF-8 的文本文件会显示成乱码。** 二进制判据是「前 64 KiB 里有没有 NUL」，一个 latin-1 的 `.txt` 过得了这道判据，然后被 `execInContainer` 按 UTF-8 解成替换字符。
5. **每次打开这一页至少一次 docker exec**，停着的容器还会被起起来（30 分钟后照常被 `sweepIdle` 收掉）。
6. **目录超过 500 项或 512 KiB 只列一部分**，界面说了「只列了一部分」但给不出「看剩下的」那条路。
7. **没有实时刷新。** 水獭在会话里新建了文件，这一页要手动点那颗刷新钮才看得见。
8. **`.` 开头的隐藏文件照列**（`find -mindepth 1` 不过滤）——`.git` 会出现在配了仓库的工作区里。判定「哪些该藏」需要一份名单，而名单是第二份要人手维护的事实。

## 验收（真机）

1. 一个没配仓库、也从没跑过 turn 的工作区 → 「文件」tab 说「工作文件夹还没建起来」，**不是**「还是空的」。
2. 同一个工作区里 @Agent 让它写个文件 → 回设置页点刷新 → 那个文件在列表里，点开看得到内容。
3. 配了仓库并 clone 过的工作区 → 列得出仓库的顶层目录，点进子目录、点面包屑退回来都对。
4. 一个大文件（>64 KB）→ 显示开头一段 + 「只显示了开头一段」；一张图 → 「这是一个二进制文件（… KB）」。
5. 停掉 runtime 再点刷新 → 上一份清单还在，底下一行红字，**不是**一片空白。
6. tab 上写的是「文件」，正文里第一句说的是水獭在这儿干活，Git 那一节在下面且标题带「（可选）」。
