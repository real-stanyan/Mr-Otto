# ADR-0286：通话那一行居中，并给每个名字左边画一张脸

- 状态：已接受
- 日期：2026-09-10
- 相关：#1228；ADR-0271（团队语音通话）、ADR-0235（云会话时间线对齐本地）、ADR-0250（中间步骤只剩一枚输入指示器）、ADR-0264（名册里查不到的不给脸）、#1068（那一行"有没有被画出来"只在渲染层看得见）

## 背景

`voice_call_changed` 在云会话时间线上投影成一行小灰斜体字（`VoiceCallRow`），文案由
`voiceCallLineText` 算成**一整个字符串**：

```
stan_test 结束了语音通话
stan_test 开始了语音通话：管理员、开发、设计
```

维护者对着真机提了两条：这一行应该**居中**，并且**每个成员的名字左边画出它的头像**。

## 决策

### 1. 这一行与旁边那几行旁白分家：居中，不再是靠左的小灰字

`AgentBriefedRow` / `AgentRelayRow` / `SystemNoteRow` 与它此前是同一款（`px-1
text-[10.5px] italic text-muted-foreground/70`），因为它们同属"审计性质的旁白"。
这个归类本身是错的：那几条说的是**机器的内务**（谁就位了、棒传给了谁、护栏喊了一声），
靠左一行小灰字就是它们该有的分量；而通话这一条说的是**整个群此刻的状态**——通话开着，
之后每条回复都会被读出来（ADR-0271），谁在里面决定了不 @ 谁时谁会接话（ADR-0270/0275）。
群聊里"这件事跟所有人有关"的通行写法就是居中。

字号、颜色、斜体**一个字没改**：它仍然不是谁说的一句话，改的只是"跟谁有关"。

### 2. 每个名字左边一张脸；名册里查不到的不给脸

头像回答的是"这几个名字是谁"。agent 可以随时改名（ADR-0221 记 id 不记名那条纪律说的
正是名字会变），脸比名字稳；而这一行恰恰是一串名字。

**查不到的那只 `avatarSrc` 回空串**，渲染层退回首字母——`agentAvatarSrc` 对陌生 id 会按
哈希派生一张，画上去等于宣称它还在名册里（ADR-0264 用量表逐字同一条）。三种情形都走
这条：已经被删掉的 agent（名字只剩事件里的快照）、已退群或没设过头像的人
（`memberAvatarOf` 本来就回空串）、`invite_to_call` 那只自己（事件上只有 id，连快照
都没有）。

### 3. 载体从"一整个字符串"换成分段，判据与文案一个字不改

一整个字符串里没有"哪一段是名字"这件事，头像插不进去。`voiceCallLineParts` 回一串
`VoiceCallPart`：`text` 那一档是连接词与标点，`party` 那一档是一个人/一只 agent
（额外带 `name` 给首字母兜底、`avatarSrc` 给脸）。

**每一格都带 `text`，一路拼起来逐字节等于原来那句话**——文案用例因此原样留在
`cloudTimelineLabels.test.ts`，只是多 join 一遍（`line()`）。"这句话怎么说"与
"这句话怎么画"共用同一份返回值，不会分成两份判据。

`voiceCallLineText` **删掉不留**：改完之后 `src/` 里没有消费方，留着就是一份看起来还
活着的死代码（同 ADR-0235 删 `timingStats`、ADR-0250 删 `foldAgentSteps` 的纪律）。

### 4. 脸走 inline，不是把整行排成一个 flex

名单长了必然换行。排成 `flex flex-wrap` 的话每一个换行后的行各自成一个 flex 行，
`justify-center` 管得到、`text-center` 管不到，而且行与行之间的对齐要另外调；
inline-flex 的脸跟着文字流走，每一行由行盒自己居中，什么都不用调。

脸与它的名字包在同一个 `whitespace-nowrap` 里：换行断在脸与名字中间，读起来就是
一张没有主人的脸。

`align-middle` 而不是一个手调的像素偏移：16px 的圆配 10.5px 的字，居中对齐在真机上
量过（见"验证"），而一个魔数偏移没有保鲜期（ADR-0236 第 1 条）。

`not-italic` 只给兜底那个首字母——外面这层是斜体，一个斜着的首字母在 16px 的圆里
认不出是字母还是划痕。

### 5. `alt` 留空

名字就贴在脸右边，读屏念两遍是噪音。

## 否决的

- **顺手把 agent 名字的「」去掉**：脸已经说了"这是哪一只"，书名号看起来冗余。没做——
  「」说的是"这是 agent 不是人"，脸说的是"是哪一只"，两件事；何况维护者没提，改文案
  是另一件事。
- **顺手把那几行旁白（就位 / 接力线）也居中**：它们的归类没变，见决策 1。
- **把这一行的字号调大**：脸变大了行自然变高，字号是另一个判断，没人提。

## 代价 / 已知未做

1. **真机一次没跑过**——云会话要连 VPS runtime。验的是一份把同一批 Tailwind 类翻成
   等价 CSS 的静态页（截图见 #1228），它盖得住对齐、换行、兜底首字母，盖不住真实
   主题变量与真实名单长度。
2. 行比原来高（16px 的脸 + 10.5px 的字）：一屏少几行。
3. 脸是满不透明的，字是 70% 的 muted——同一行里两种分量。真机上看着刺眼的话，该调的
   是脸的透明度不是字的颜色（字的分量是决策 1 明说不动的那一格）。
4. 渲染层改动，**要发一版客户端才到得了用户手里**（同 #558 / #906 那一族）。服务端
   一个字没碰。
