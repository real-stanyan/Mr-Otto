# ADR-0339：好友在线点——手机 App 在前台算在线，没报过不画，红绿是借形

日期：2026-10-04 · issue #1460 · 维护者在会话里定的口径

## 决定

1. **在线 = 手机 App 在前台**（维护者选的）。前台时每 60 秒报一次心跳（`touch_presence(true)`），切到后台报一次
   `false`，退出登录前报一次 `false`。App 被杀掉或断网时报不了 `false`，所以心跳 150 秒没更新也算不在线
   （`PRESENCE_STALE_MS`，比两次心跳宽，iOS 推迟定时器、晚到一次不会闪红）。
2. **对方从没报过就不画点**：还在旧版本的、只用桌面的，都属于「不知道」。画红点等于替他说了一句「不在线」。
3. **只有已接受的好友读得到**（`presence` 的读策略）。别人不该知道我此刻开没开着 App。只能经 `touch_presence`
   写，不然就能替别人报在线。进 realtime，好友那边当场变色。**从不删行**，理由同 0044 / 0049（DELETE 不查 RLS）。
4. **绿 = 在线、红 = 不在线**（维护者指定）。本 App 的规矩是红只用来说「出事了」（`Badge.tsx` 头注、DESIGN.md），
   不在线不是出事。这里是维护者点名要的借形，同 ADR-0240 Max 徽章借 `--warn` 的形：哪天要调错误红，先想起这里还挂着。
5. 画在四处：聊天列表里的朋友私聊（头像右下）、通讯录好友（头像右下）、朋友私聊顶部（名字下一行点 + 「在线 / 不在线」）、
   朋友资料页（头像右下）。智能体那几种行右下角是状态角标，朋友行没有，两枚不打架。

## 代价

- 桌面不报：只开着桌面的人，在手机上看是红点（他报过一次手机在线之后）。
- 没有隐私开关（维护者没要）。想要的那天，在设置 → 隐私里加一格，关了就不再报。
- 退出登录时如果 signOut 失败，心跳已经停了，150 秒后自己会显示不在线，下次回到前台才恢复。
- 部署顺序：先跑 0050，再发手机包。反过来时心跳报「函数不存在」，头像不画点，不出别的事。真机一次没跑过。
