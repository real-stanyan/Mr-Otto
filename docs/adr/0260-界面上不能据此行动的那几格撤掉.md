# ADR-0260：界面上「不能据此行动」的那几格撤掉

- 状态：已接受
- 日期：2026-09-08
- 关联：#1091 / #383（请求信封落盘）/ ADR-0235 ①③（云会话把这两条藏起来）/ ADR-0250（云会话连折叠行也撤）/ ADR-0254（浮层给订阅用户删掉钱）/ ADR-0241（不许编一个用户没花过的数）/ ADR-0206（任务会话拿子文件夹）/ ADR-0211（合计混着就不报）/ ADR-0214 · ADR-0249 · ADR-0250（死代码一起删）

## 背景

维护者对着 dev 一口气点了四处：

> 「请求信封已更新：deepseek-v4-flash · 思考 on · 工具 17 把」这个文本信息不用显示了
> 订阅用户不用显示 cost 了
> header 里面不要显示那个 s-xxxxxx
> 「会话已创建」这个文本也不用显示出来

## 诊断

四处是同一句话的分身，而那句话 ADR-0235 ③ 已经立过一次（当时只对云会话说）：**这条事件说的是对话里发生的事，还是机器的内务**。

这次把它磨得更锋利一点，因为「内务」对着一格数字不好用：**用户能不能据此做点什么**。

`isAuditEvent` 今天放行的那批，每条都过得了这一关——`model_changed` 是「之后的话由谁说」（换回去是一个动作）、`branch_checked_out` 是「这段话在哪份代码上说的」、`session_shared` 是那个动作唯一的痕迹、`route_changed` 是钱从谁账上出变了。这四处一条都过不了：

| 那一格 | 说了什么 | 能据此做什么 |
|---|---|---|
| `request_envelope` | 工具从 16 把变成 17 把 | 没有——它是给维护者调参用的 |
| 页脚 `cost` | 厂商按量价乘 token | **不只是没有，那个数还是错的**——订阅用户付的是月费 |
| 头部 `s-2026…` | 任务会话的子文件夹名 | 没有——那不是用户起的名字 |
| `session_created` | 「会话已创建」四个字 | 没有——而它必然是每条会话的第一条事件 |

第三处还不只是噪音，是**一条悄悄失效的规则**。头部那句注释写着「内置 Default 工作区不显示文字——「Default」是系统内部名字，不是用户起的」，判据却是 `workspace !== builtinWorkspace`；而 ADR-0206（#851）之后任务会话拿的是 `<Default>/<sessionId>/` 这个**子目录**，等号判据从那天起就漏掉了它们。规则想挡的正是这种东西，只是没人回来改判据——而它的失败模式是安静的（不报错，只是多写一串 id）。

## 决策

### 1. 判据是「能不能据此行动」，落点是 `isAuditEvent` + `EventRow` 两份名单

`request_envelope` 与 `session_created` 都从放行组挪走，两处一起改（`tests/renderer/timelineLists.test.ts` 对着这两份名单）。

`isAuditEvent` 那侧写**显式 `return false`**，不是删掉 case 落 `default`：落 default 得到同一个答案，但那是「碰巧对」，`default` 的语义哪天变了这条没人会注意到——同一个文件里 `section_classified` / `session_topic_assigned` / `checkpoint_created` 都是这么写的。

### 2. 撤的是投影，不是事实

两条事件照旧落盘、照旧去重。`request_envelope` 仍是「这次请求由什么拼出来」的唯一凭据，`sessionPackage` 的隐私闸（`PRIVACY_VERDICTS` 里它是 `strip`，烤着 system prompt 全文）也要它继续在；`session_created` 更是投影的原料（`workspace` / `isolated` / `cloud` 三个字段各自决定 system 提示词多注入哪一段）。

`replay/trajectory.ts` 的 `default` 分支照旧把它们画成 system 行——调参的人本来就该去轨迹视图，而**为了一个维护者场景在每个人的对话里常驻一行**正是这条 issue 要修的东西。

### 3. 页脚的钱：判据是**这条消息自己的 `route`**，不是「此刻订没订阅」

页脚报的是**已经发生的事**，而订阅是**此刻的状态**——退订过的人那些 hosted 行确实由额度承担过，订阅之前那几笔 direct 是真金白银。同 ADR-0254 的 `showsCost` 为什么不判 `isSubscribed`。`route` 缺席 = direct（旧日志 / 子会话），照旧计价。

**不给替身**：不写「本次用掉额度的 0.4%」那类数（ADR-0254 里维护者砍掉过一次——换了单位仍然在回答「这一次花了多少」），也不改写成 credit：页脚只有四格、每格一眼扫过，混着两种单位读的人得先分辨这一格是哪一种。

与「算不出价钱」共用 `undefined` 这一档：页脚上两者的正确表现同为**不出这一格**，而它没有位置说清楚是哪一种（花费面板有，那边照旧分开画「托管」与「—」，ADR-0211/0241）。一个 turn 里混着两条路时整段不出 cost——同「有一条算不出价钱整段就算不出」那条规矩：报一个只算了 direct 那半的残数，看着像这一轮的全部花销。

### 4. 头部那一格：判据换成 `isDefaultWorkspace`，分隔点跟着走

`workspace !== builtinWorkspace` → `!isDefaultWorkspace(workspace, builtinWorkspace)`，用的是 ADR-0206 那天就为这件事写好的纯函数（等于 Default 根 **或** 父目录是它）。

分隔点搬进条件里面（同 `BranchPicker` 的 `leadingSep`，那个参数的注释就写着为什么）——不搬的话，改完之后每个任务会话的头部都留一个孤零零的「·」。**这是改动前就有的形态**（工作区正好等于 Default 根的老会话），只是这次它会从「少数旧会话」变成「每一条任务会话」。

### 5. 顺手删掉 `timingStats`

`src/` 里零调用——页脚走的是 turn 那份（`turnTimingStats`），这份是被它取代的每条消息一行的旧版。留着它意味着这次「钱怎么显示」的修法有两份，其中一份没有任何消费方却看起来像活的（同 ADR-0249 删 `ModelMenuItem.vision`、ADR-0250 删 `foldAgentSteps` 的理由）。它的测试块跟着删——**动机是产品代码在同一个 diff 里删了**，不是为了让门禁变绿。

### 6. 断言钉的是决定，不是实现

两条名单对表那条（`timelineLists.test.ts`）管的是**两处一致**——两处一起把某个类型加回放行名单，它照样绿。所以另钉：`request_envelope` 与 `session_created` 各自「投不出任何消息」「夹在两句话中间不留白行」。已验红绿。

头部那一格**没写断言**（同 ADR-0236 第 1 条）：它是 JSX 里的一个条件，而判据本身（`isDefaultWorkspace`）早就有测试；写出来只钉得住「调了这个函数」。保鲜期在紧挨代码那段注释里。

### 7. 上下文浮层那半：病不在「画不画」的判据上，在**记账**上

维护者随后指出浮层里那一段仍然在（一个 Max 用户，卡上还挂着 `<$0.01`）。ADR-0254 的判据没错——`showsCost` 问的是「日志里有没有一笔走自己的 key」，而这条会话的日志里**确实有一笔被记成了 direct**。

病在 `deriveUsage.billed()` 里这一行：

```ts
route: e.type === "assistant_message" ? (e.route ?? "direct") : "direct",
```

它带着一句写在旁边的依据：「外挂小调用（压缩/分区/建议…）没有 route 字段，按 direct 记（**这些账目前只走用户自己的 key**）」。那句话在写下的那天是真的，**ADR-0248（#1051）让订阅用户的小模型改走托管之后就成了假的**——`helperHostedRoute()` 拿到路由、`annotateTurn`/`microCompactOnce` 真的打了托管网关，而落盘的那几条事件只带 `model` + `usage`，一格 `route` 都没有。

后果是两层，第二层更贵：

1. `showsCost` 判 true → 订阅用户那半张卡整段冒出来（ADR-0254 白做了一半）
2. `money()` 走 direct 分支 → 按价目表给它标一个 `<$0.01`，而那是**用户没花过的钱**——正是 ADR-0241 点名不许的那件事

而 `context_compacted` 更刺眼：#1017 已经给它补上了 `creditCostMicro`（真实结算的 credit 就落在事件上），却没补 `route`，于是 `deriveUsage` 把一条**自带 credit 的账**判成 direct，转头按 $ 给它计了价。

修法是把那句依据变成日志里的一个事实：六类计费事件（`context_compacted` / `section_classified` / `suggestions_generated` / `micro_compacted` / `session_autotitled` / `session_topic_assigned`）各加一格可选的 `route`，`billed()` 从此**不分事件类型**一律 `e.route ?? "direct"`。

三条纪律：

- **`route` 跟着 `usage` 走，不单独挂**。annotate 那一路一次调用落四条事件、账只挂先落的那条（`billOnce`）——分开挂的话另外三条会各带一个没有账的 `route`，读起来像三笔。
- **缺席仍按 direct**，不改默认也不加 `unknown` 一档：旧日志里它们**确实**是 direct（ADR-0248 之前订阅用户根本没配 key，那三个外挂按 ADR-0248 的原话「从来没跑起来过」）。
- 断言要**从事件日志推一遍**。`tests/renderer/CostPanel.test.tsx` 原来喂的是造好的 `ModelUsage`，于是它对这个 bug 结构性地失明——出错的正是「事件 → 行」那一步。新加的两条走 `CostPanel({events})` 整条路。

## 代价与已知未做

1. **轨迹视图里那两行是光秃秃的事件类型名**（走 `systemSummary` 的兜底），型号 / 思考挡位 / 工具数得点开才看得到。没顺手给它们写 summary：那是另一个页面的活。
2. **换了思考挡位、接了一台 MCP，界面上从此没有任何提示**。这两件事各自有自己的入口，信封那一行本来就不是它们的通知渠道——但确实是曾经唯一会说出口的地方。
3. **订阅用户的页脚从此三格**，「这一轮烧了多少额度」在页脚上没有答案（那个问题的正式出口是上下文浮层那两只表 + 账号页，ADR-0209/0239/0254）。
4. **任务会话的头部只剩会话名**（工程那一格整个不画）——想知道它落在哪个文件夹，得去 Files 面板或「更多」菜单。这正是 ADR-0206 的原意（那个文件夹名是系统铸的），但它同时也意味着**「打包为项目」之前你看不到产出在哪**。
5. 存量日志里的那些事件不会消失，只是不再画出来——重放旧会话与新会话看到的是同一个样子（投影改了，日志没动）。
6. **已经写下的那些外挂调用永远是 direct**。`route` 是新字段，append-only 的日志补不回去——所以**这条会话修好之前开的会话，浮层里那一段还会在**（还带着那个假的 `<$0.01`）。新会话从此干净。不做迁移：改写历史事件比留着一条读得懂来历的旧记录更坏。
7. **这几笔的 credit 没记到**（`annotateTurn` / `microCompactOnce` 都不回传 `creditCostMicro`，只有 `context_compacted` 有）。所以混着 direct 的会话里它们显示成「托管」而不是一个数——那是诚实的（「这笔没记到」≠「0」），但 `sessionTotal` 因此永远退回 token 总数。要补得让那两条路把网关的结算数带回来，是独立的一件事。
8. **代读员（`image_described`）压根不在账上**——它没有 `usage` 字段，`BILLED_EVENT_TYPES` 里也没有它。每条带图消息都真跑了一次视觉模型，而这本账从来没算过。不在本条射程里，另开 issue。
