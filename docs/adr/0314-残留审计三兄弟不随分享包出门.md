# ADR-0314：残留审计三兄弟不随分享包出门

- 状态：已采纳
- 日期：2026-09-21
- 关联：#780（M3）、#759 / ADR-0193（残留物生命周期）、#611 / #850（分享会话的隐私闸与穷尽表态表）

## 背景

新会话开工前，装配根拍一张现场照落进日志（`residue_baseline`）：**整台机器**此刻所有的
LISTEN 端口、每个监听进程的命令行、所有 booted 模拟器。归档那一刻再拍一张做全量 diff，
差出来的条目落 `residue_detected`，清理结果落 `residue_cleaned`。

这三条事件在 `PRIVACY_VERDICTS` 里一直写着 `keep` —— 也就是说，把一条会话分享给好友时，
上面那张整机照片连同命令行原样进了发给对方的包。

#780 把这一条记成「M3：residue_baseline 把整机 LISTEN 端口+进程名写进会话日志，
日志有分享/代理通道——主机指纹，考虑瘦身」。

## 决定

三条一起翻成 `strip`。

判据就是那张表自己立的那一条（#850）：**这条事件说的是「这段对话」，还是「发送方这台机器 /
这个人的私事」？** 三条都落在后者：

- **`residue_baseline`** 照的本来就是**别人的东西**。这不是修辞——`diffResidue` 拿它当
  「本来就有」的底片，正因为它照的是跟这段对话无关的那些端口和模拟器。
- **`residue_detected` / `residue_cleaned`** 里的条目同源。`owned` 那一档确实是本会话
  agent 自己起的命令，但那份事实 `tool_result` 里已经有了（`python3 -m http.server 9999 &`
  就写在日志正文里）；而 **`suspected` 那一档是会话期间机器上新冒出来的任何端口/模拟器，
  不论是谁开的**——用户自己另开一个 app 也会进这张清单。发出去等于顺手汇报
  「我在跟你聊天这段时间里还干了什么别的」。

## 为什么代价是零

这三条事件在接收方那边**一个消费方都没有**，逐个查过：

- **时间线不画它们**：`isAuditEvent` 与 `Timeline.tsx` 的 `EventRow` 两份名单里
  `residue` 一个字都没有（那两份名单有断言互相对表）。
- **残留面板只吃直播推送**：`applyResidueEvent` 挂在 `CHANNELS.event` 上，导入一份包
  不会重放出这些推送。
- **重放侧那几个查询要么先问 `world.residue`**（导入的会话在 B 机器上没有基线，
  `currentResidueDiff`「没有 baseline 就不做」那道守卫直接回空），**要么本来就只扫本机**。

所以这不是「牺牲一点功能换隐私」，是删掉一份纯粹的泄露。

## 没碰的另一条通道

任务会话的日志上云（`src/shared/taskSync.ts` 的 `PEN_VERDICTS`，`residue_baseline: "executor"`）
仍然带着这三条。那是**用户自己的账号、自己的库**，不是给别人的副本——#780 M3 说的
「分享/代理通道」指的是前者。要不要连这条一起瘦身是另一个判断（它牵涉
云端兜底执行器 #1253 能不能看见基线），本条不做。

## 也没做「瘦身快照本身」

#780 的原话是「考虑瘦身」。查下来 `diffResidue` 只读基线的 `ports[].port` 与
`simulators[].udid` 两格——`command` / `pid` / `pgid` / `name` / `runtime` 写进了日志却
**没有任何代码读**，看起来正该删。没删，两条理由：

1. **瘦身治不了这条 issue 说的病**。一台机器上正在听的端口号本身就是指纹
   （5432 / 6379 / 11434 各说明一件事），删掉进程名只是把指纹变模糊，而闸门那一侧是
   「要么出门要么不出门」。真正止血的是 strip。
2. `persistencePolicy` 把这条事件记成「初始状态的**审计凭据**」——审计是给人读的，
   「端口 3000 在开工前就被谁占着」这个问题只有 `command` 答得出。为一个已经被 strip
   堵住的泄露去削审计价值，方向反了。

## 已知代价

1. **分享出去的会话再也看不出「这一轮留下了什么没清」**。这条真丢了，但它对接收方
   本来就没有出口（上面那三查），而发送方自己的日志一个字节没动。
2. **存量已经发出去的包收不回来**——append-only 管的是源日志，发出去的副本不归它管。
3. `manifest.stripped` 从此可能多三个类型名。那正是它存在的意义（「这份包被剥过什么」
   可审计），但如果有人拿 `stripped` 的长度当「这份包干不干净」的判据，那个数会变。
