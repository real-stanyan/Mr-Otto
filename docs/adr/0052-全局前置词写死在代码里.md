# ADR-0052: 全局前置词写死在代码里，不给用户改

- 状态: 已接受
- 日期: 2026-08-21
- 相关: ADR-0048（三层前置词，本 ADR 推翻它的决策 2）、ADR-0051（内置子智能体）

## 背景

ADR-0048 把前置词做成三层：内置默认 → 用户可编辑的全局那份
（`~/.otter/subagent-preamble.md`，设置页一张卡）→ 每份定义自己的三档
（自定义 / 不加 / 用全局）。

中间那一层现在删掉。

## 决定

`DEFAULT_PREAMBLE` 是唯一出处，写死在 `src/shared/subagent.ts`。
`preamble: { mode: "default" }` 的语义从「读磁盘上那份，没有就用内置」变成
「用内置那份」。定义文件的格式不变，老文件照旧可读。

一并删掉：`getSubagentPreamble` / `saveSubagentPreamble` 两条 IPC 通道、
`GlobalPreambleCard`、`readGlobalPreamble`、`GLOBAL_PREAMBLE_PATH`、
store 里那份状态，以及它们各自的测试。

正文改成英文。

## 理由

**这段话说的是协议事实，不是偏好。**「你的最终一段文本就是返回值」「你看不到父会话
和用户的对话」——它们描述的是这个 harness 的运行方式，不是可以见仁见智的风格。

**改坏了没有反馈。** 用户删掉「最终一段文本就是返回值」那句，此后每个子智能体都会
开始写「好的，我帮你看了一下～」，而父 agent 拿到的返回值就是那句寒暄。界面上不报
任何错，日志里一切正常，只有结果慢慢变差。一个改坏了不会响的旋钮，比没有这个旋钮糟。

**需要覆盖的场合已经有出口。** 每份定义自己的三档还在。真要一段完全不同的开场白，
写在那一份定义里——那是有边界的，坏了只坏一个子智能体。

**它原本能站住的两条理由都不够。** 一是语言（改成英文之后这条自己消失了，而且以后
做多语言换掉这一个常量就够）；二是「对全部子智能体一起生效的家规」——但 ADR-0048
决策 1 定的是**自定义前置词替换全局、不是追加**，所以家规只对「没写自定义前置词的
那些」成立，这个用途本来就半残。

## 接受的代价

- **想改这段话得改代码。** 这是个个人工具，代价可以接受；但如果以后要给不写代码的
  人用，这条得重新算。
- **前置词从此是中英混排。** 内置那段是英文，用户写的自定义前置词多半是中文，正文
  也是中文。选英文是因为模型对英文指令的服从度更稳，而这段话是给模型看的。
- **已经写过 `~/.otter/subagent-preamble.md` 的人，那份文件从此被无视**，而且没有
  任何提示。这次删除时那个文件在本机不存在，所以没有实际迁移；如果将来发现有人在用，
  该补一条启动时的告知，而不是静默忽略。
