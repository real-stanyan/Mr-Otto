# ADR-0131：液态玻璃卡片用位移贴图，不是"加厚的模糊"

> 原为 ADR-0129 —— 合并前 re-fetch 发现 0129 已被 main 上另一篇占掉（ADR 的号在合并时 claim）。
> 本 PR 的 commit message 里指的 ADR-0129 就是这一篇。

日期：2026-08-26
状态：已接受

## 背景

运行指示条（`RunIndicator`，OttoThread.tsx）此前是一行裸文字，浮在滚动的正文之上。
要给它一张卡片托底，方向参考 rdev/liquid-glass-react。

一张"液态玻璃"和一张"半透明毛玻璃"的差别不在模糊的强弱，在**边缘会不会折射**：
真玻璃的正中央看过去是直的，越靠边，背后的东西被推得越歪。CSS 只有 `blur()`，
它把画面糊掉，但推不歪任何东西——把 `backdrop-blur` 调厚，只会得到一块更脏的白板。

## 决定

三件事凑成一块玻璃，各有分工，落在不同的层：

1. **折射**——`backdrop-filter: url(#filter)` 挂一条 `feDisplacementMap`。
   贴图由 `src/renderer/src/lib/liquidGlass.ts` 现生成：红通道管 x、绿通道管 y，
   `#808080` 是中性；四边留一圈渐变带，中央盖一块模糊过的 `#808080` 圆角矩形。
2. **模糊 + 饱和**——让背后安静，正文读得清。留在 CSS（`.liquid-glass`）。
3. **高光边**——一圈内投影模拟倒角受光。没有它，玻璃没有厚度，只是一层膜。

配方留在 CSS，组件（`components/LiquidGlass.tsx`）只做两件 CSS 干不了的事：
用 ResizeObserver 量出真实尺寸、把对应的滤镜挂上去。**尺寸必须真量**——
贴图被拉伸的话，圆角处的折射会跟着拉成椭圆，在胶囊形的状态条上一眼就看得出来。

折射强度不走内联样式，走 `--lg-refract` 变量：内联样式压得过类，
`prefers-reduced-transparency` 那条 media query 就盖不住材质了。

## 取舍

- **只在 Chromium 上成立**。`backdrop-filter` 吃 `url()` 滤镜是 Chromium 的能力，
  Safari / Firefox 上整条声明被丢掉，剩下底色和高光边——仍然是一张能读的卡片。
  本仓是 Electron，这是既定前提，不是赌运气（手机端那侧另说，那边没用这个组件）。
- **底色不能太实**。折射发生在背后的画面上，底色越不透明看到的越少；
  对比度靠底色 + 高光边给，不靠加厚模糊。
- **玻璃是给这一条挑的，不是全局皮肤**。运行指示条悬在滚动的正文之上、
  只在 turn 跑着时存在——折射有东西可折。静止的面板上放同一块玻璃只剩模糊。

## 这套做法唯一的失败模式，和它为什么必须有测试

`backdrop-filter` 里但凡有一段解析不了（滤镜 id 带 CSS 非法字符、贴图 data URI 里的
`#` 没编码、SVG 没挂进文档），**整条声明被静默丢弃**：控制台一个字都不说，
画面只是"少了点材质"。React 19 的 `useId` 返回 `«r0»`——两个书名号就足以让它全没。

所以两层都钉住：`tests/renderer/lib/liquidGlass.test.ts` 钉贴图和 id 的生成，
`tests/e2e/runIndicatorGlass.e2e.ts` 在真 app 里断言算出来的 `backdrop-filter`
里确实有 `url(...)`、且它指向的 `<filter>` 在文档里找得到。
