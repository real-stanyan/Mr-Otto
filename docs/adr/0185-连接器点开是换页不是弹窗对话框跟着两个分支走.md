# ADR-0185：连接器点开是换页不是弹窗，对话框跟着两个分支走

- 状态：已接受
- 日期：2026-08-29
- 相关：issue #745、ADR-0171（两层目录）、ADR-0184（目录扩到 82 条）、issue #722（勾撒谎）

## 背景

目录卡上只有：图标 + 名字 + 一行**被截断**的描述 + 一颗按钮。装之前用户看不到地址、
看不到要填什么、看不到"代码跑在谁的机器上"；装之后也看不到这台到底给了哪些工具。

82 条之后这件事更明显：卡片是索引，不是答案。

## 决策一：换页，不是弹窗

弹窗装不下工具清单（一台连上的 server 可能有二三十个工具），要么滚动条套滚动条，
要么把上下文整个盖住。而用户点进来正是为了「先看清楚再决定」——盖住他刚才在看的
东西是反的。

所以是面板内换页：目录整块被详情页替换，左上角一个「← 连接器」。下面那份本机 server
清单也跟着让位（`onPageChange` 回调）——不然"新页面"底下还挂着上一页的尾巴。

## 决策二：主行动那一格复用 `installSlot`，一个字都不另写

详情页右上角那颗按钮和目录卡右边那一格是同一套四档判据。两处各写一份的话，
「装上了但还没授权」这种状态迟早会在两个地方说两句话——issue #722 就是一格勾
撒谎撒出来的，判据分叉是那个 bug 的一般形式。

差别只在这一页有地方写字：卡片上是一颗 24px 的图标钮，详情页可以把动词说出来
（「添加」而不是一个 `+`）。

## 决策三：打开的是 id，不是 item

`openedId: string | null`，渲染时从当前这一轮 `buildDirectory` 的结果里现查。

存整个 `item` 会有一个只在装完之后才出现的 bug：`item` 每轮都是新对象，存下来的
那份会停在打开那一刻的状态——卡片切成 ✓ 了，详情页上还写着「添加」。

## 决策四：两道对话框跟着两个分支一起挂

**这一条是这次差点出门的错**：`InstallConfirmDialog` 和 `ParamsDialog` 原来只渲染在
网格那一支的 `return` 里。详情页上点「添加」，`filling` 状态设了、对话框根本没渲染
——按钮点下去一声不响，没有任何报错。

所以把两道框提成一个 `dialogs` 节点，两个分支都挂。`tests/renderer/McpDirectory.test.tsx`
里有一条钉住它（验过非空转：把详情页那支的 `{dialogs}` 删掉会红）。

一般教训：**一个组件长出第二条 return 路径时，挂在旧路径末尾的"全局"节点都要重新过一遍**
——它们看起来像是挂在组件上，其实挂在某一支上。

## 决策五：卡片可点用 role+tabIndex，不是 `<button>` 包整张

右边那颗按钮还在，`<button>` 套 `<button>` 既非法、也会让读屏器读出两层可点。
卡片用 `role="button"` + `tabIndex` + 键盘处理，里面那颗按钮 `stopPropagation`。
有一条断言钉住"点加号不会顺手把人带进详情页"——不拦冒泡的话，用户点了「添加」
会看着一个陌生页面，不知道自己刚才装没装上。

## 决策六：动画只做进场，返回是瞬时的

进场 8px 从右推入 + 淡入，200ms，`--ease-strong`。位移只有 8px：这不是叠加层而是
**换页**，同一块地方的内容被替换，大幅位移会让人以为出现了第二层。

返回不做动画。返回是高频动作，而且列表本来就在用户脑子里——补一段退场只会让"回去"
变慢（退场永远比进场快，这里快到 0）。`prefers-reduced-motion` 下去掉位移，只留淡入。

卡片按下用 `.press-card`（0.985）而不是既有的 `.press-scale`（0.97）：卡片有 240px 宽，
缩 3% 会把旁边的卡衬得在动。

## 后果

- `InstalledServer` 多一个可选的 `tools`。可选是刻意的：目录卡不需要它，不该为了一张卡
  把整份快照传进来。
- `EntryIcon` 接受尺寸参数（详情页用 40px）。尺寸走 `style` 不走 `size-[${n}]`——
  拼出来的类名静态扫不到，生产构建里根本不会生成。

## 被否掉的路

- **弹窗**：见决策一。
- **详情页自己再实现一遍安装流程**：判据分叉，见决策二。
- **把详情页状态提到 McpSettings**：那样安装/授权的状态机也得跟着搬上去，或者拆成
  一个 hook 两处用。现在这样只有一个 owner（McpDirectory），代价是多一个
  `onPageChange` 回调，比搬状态机小。
