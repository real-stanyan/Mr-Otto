# ADR-0264：工作区设置改推入式导航；用量页从 credit 换成窗口百分比

- 状态：已接受
- 日期：2026-09-09
- issue：#1120（合并 #1115）
- 相关：ADR-0198/0217/0218（工作区设置这一页的来历）、ADR-0209/0239/0241/0233（额度怎么报）、
  ADR-0185（换页不是弹窗）、ADR-0243/0251（「读不到」不许说成「里面是空的」）、
  ADR-0236 第 1 条（几何不写成断言）

## 背景

维护者对着真机点的。两件事，各自独立成立：

**① 七格挤在 420px 里。** 抽屉宽 `w-[min(420px,92vw)]`（`App.tsx`），里面塞着七个
`TabsTrigger`（会话 / 智能体 / 文件 / 连接器 / 成员 / 用量 / 记忆）。真机上「智能体」
「连接器」已经挤到快认不出，再加一格就得开始截断。同一屏上视觉最响的元素是页头右上角
那颗红色实心的「解散工作区」——**最危险、最少用的那一个占了视觉锚点**。

**② 用量页在报钱。** 那一格报的是 `12.3 credit`（`fmtCredit`）。credit 是一笔钱数
（1 credit = 1 美分，`src/shared/billing.ts` 头注），而云会话统一走**所有者的订阅额度**
（ADR-0233）——那笔钱在月费里。ADR-0241 已经为 `CostPanel` 判过同一条（「按量价抄过来
就是编一个用户没花过的数」），ADR-0209/0239 为账号页与浮层定的口径是「报还剩百分之几，
不报 credit」。工作区用量页是这一族里没跟上的那一格。

顺带撞上一条开着的 #1115：「会话」tab 只列**归档**的云会话，一条都没有时整节不画——
于是最常见的情形（有会话、都没归档）是一片空白，而它叫「会话」，还是点 ⚙ 落地的第一格。

## 决策

### 1. 七格从分段控件换成推入式导航

根页是一份七行目录，点一行推一页；返回钮 + 左缘右划返回。换来三件事：

- 每一格有多宽由它自己说了算，加第八格不影响前七格；
- 目录那一层能给每行写一句**「里面有什么」**（tab 只有两个字）；
- 二级页有完整一屏，于是三个原来必须开弹窗的编辑器可以直接摊开。

**代价明写：换一格从一次点击变成两次。** 设置面是低频、且人来这儿通常只为改一件事，
这个代价换上面三条划算；哪天这一页变成每天要在几格之间来回跳的东西，这个判断就该重判。

否决的另一条是「保留分段控件、做成可横滚」：它把「装不下」这个事实藏进一个要划一下
才发现的地方，而目录那一层顺带解决的「每格里面是什么」它一条都答不了。

### 2. 目录行那句 hint 只从已经在手的 `ws` 推

为了给目录写一个数就多打一次网络，等于让「打开抽屉」这个动作变贵。而这句话的活是
**「让人知道该点哪一格」不是报数**——「用量」那行写的是「各智能体占了多少额度」，不是
一个百分比。

这条顺带堵掉一类洞：这轮第一版里目录行写着 `本周 $1.86`，而点进去的那一页已经换成
百分比了——**同一个事实两份写法，改一处忘一处不报错**。

### 3. 「解散工作区」搬到最底下

红字、单独一组、页面最末。`confirm()` 二次确认不动——不新造一套 AlertDialog 视觉语言
（同 FriendsSection「删除好友」、侧栏「删除会话」，本仓这一类判定至今都是这么做的）。

### 4. 动效自己写一层弹簧，不引依赖

`lib/spring.ts`：Apple 那套两参数口径（response 秒 / damping 阻尼比）+ 动量投影 +
越界阻尼 + 速度采样。**纯的**——时间由调用方一帧一帧喂进来，所以整层进得了单测。

- 不用 CSS transition：定时曲线抓不住半路反向。用户可以在**任何时刻**抓住一页把它拖
  回去，而 transition 在半路改目标时只能从当前值起一条新曲线，速度在那一刻断掉。
- 不引动画库：要的就是这三十行，而加一个依赖是 Tech stack 改动（AGENTS.md 的 L1 档）。

三个会安静出错的地方各有一条断言钉着：掉帧（dt = 2s）时显式欧拉一大步会把弹簧炸出屏幕
（子步封顶 4ms）、两个 `pointermove` 挤在同一毫秒能算出荒唐的速度（封顶 6000/s）、
临界阻尼从静止出发不许过冲。

**副作用不写在 `setState` 的 updater 里**：StrictMode 会把 updater 跑两遍，一次返回就会
推两条退场记录、起两条动画。改成读 `stackRef` 再显式改两处 state。

`prefers-reduced-motion` 下整层退化成**瞬切**，不是「快一点」。

### 5. 列表语言：分组卡 + 内缩分隔线 + 组尾解释

换掉「每行各自一圈 `border border-border`」那套：12px 的字配满屏细框，一屏十几个矩形
边全是等价的视觉重量。分组卡的三件事各有活干——卡的边界说「这几行是一组」、内缩到与
文字对齐的分隔线说「组内还分行」、组尾那段小字说「这一组是怎么回事」。

- **分隔线内缩量按组给不按行给**：同一组里前导槽位一致，给每行各自算只会画出参差的线头。
- **图标底座中性，不上彩色方块**：本仓的颜色只用来说「出事了」（ADR-0209/0239/0240），
  给每个分区安一种彩色会把这条纪律稀释掉。Apple Settings 那种彩色方块是这次**故意没抄**
  的一处。
- **行用高亮不用缩放**（一列行里某行忽然缩小会打断整列基线），按钮反之。
- 能点的行**不是一颗 `<button>`，是 div + 一层铺满的透明按钮**：行尾经常还要挂一颗自己
  的按钮，而 button 套 button 是非法 HTML（#1044 已经为这件事拆过一行）。代价：读屏念的
  是 `label ?? title` 而不是行里那串可见文字。

### 6. 三处编辑器从弹窗变成推入页

智能体编辑器 / 添加主机 / 记忆编辑。420px 的抽屉里开一个 `sm:max-w-[480px]` 的弹窗本来
就不成立——它一直靠 `92vw` 缩着用。摊成一页之后 #997/#998 那套「DialogContent 没有
max-h/overflow 兜底」的账在这三处自动清掉：页自己就是一个 `min-h-0` 的滚动区。

两处跟着简化的东西值得记下来，因为它们说明这不只是换个容器：

- 智能体编辑器那个「open 变化时把七个 useState 重置一遍」的 effect **整段删了**——它存在
  的全部理由是弹窗常驻在树上、开合只是换个 prop；推入页每次都是全新挂载。
- 记忆那套「谁有未保存草稿」的记账**整段删了**——它存在的理由是「刷新会把所有块一起卸载
  重装」，而站在编辑页上根本够不到列表那颗刷新（它在上一页），这个情形在结构上不再存在。

「添加主机…」的省略号跟着去掉：在这套约定里省略号是给弹窗留的。

### 7. 用量页：credit → 占所有者本周额度窗口的百分比

整页一个 credit 都不出现。分母是 `WorkspaceUsage.weekLimitMicro`，**新加的字段**——
`fetchWorkspaceUsage` 已经把 owner 的订阅行读出来了，`planSnapshotOf` 里就是
`week_limit_micro`，所以是给响应加一格，不是新查一次库。没订阅时**根本不查 plan 表**
（分母无论如何是 null）；档位查不到也回 `null` 不挑一个顶上——分母错了那一页每个百分比
都跟着错，而它不会以任何方式报错。

- `usedPercentOf` / `fmtUsedPercent` 挂在 `remainingPercent` 旁边：同一把尺子的两头
  （那边报剩余、这边报已用），**一位小数向下取整**的理由也是同一条（四舍五入会把
  「刚烧了一点」写成一个更大的数）。
- 行里的条按**本工作区合计**归一化（各行加起来正好是 hero 那个数），**不按最大值**——
  那样花得最多的那只常年满格，而一根满格的条会把「一切正常」画得比「快没了」还响
  （同 ADR-0239 对主条的处置）。一律中性灰。
- 每只 agent 画脸；**名单里查不到的（已删除 / 未归因）不给脸**：`agentAvatarSrc` 对陌生
  id 会按哈希派生一张，画上去等于宣称它还在名册里，而这一行的名字恰恰是「查不到，只剩 id」。
- **分母缺席时不回落到 credit**，退回「占本工作区本周合计」并**在组尾说明换了口径**
  （两个分母算出来是两个意思完全不同的数）；页顶那格此时只报调用次数，不拿合计当分母
  硬报一个 100%——那句话什么都没说。

**明确不做**：不报「所有者还剩多少」。那要 owner 跨工作区的全量用量（另一个聚合），
而账号页已经画着那两扇窗，这里再画一份就有了同一扇窗两个数的风险（ADR-0209 明令不许）。
这一页只答「这个工作区吃掉了多少、谁吃的」。也不画 5h 窗——这个端点本来就是周口径。

### 8. 会话页列全部云会话（#1115），并把「读不到」与「一条都没有」分家

当初「这里只是归档的去处」的理由（ADR-0217「入口留两个只会让人以为它们是两样东西」）
成立不代表代价付了：结果是最常见的情形下这一屏是空白。同一个判据 #1056 已经下过一次
——**一个叫「文件」却一个文件都列不出来的页面是 #722 撒谎的勾的近亲**。

判据改成 `undefined` vs `[]`（同 gitHosts 那份 `null` vs `[]`）：没有那一格 = 从来没
成功读到过，配一句「读不到」加一颗重试；`[]` 才是「这个工作区还没有云会话」。中间还要
一档 `loading`，否则刚挂载那一帧会对着「还没拉过」喊读不到。侧栏那份不动：那边答
「我现在要进哪条」，这边答「这个工作区有哪些」。

## 已知代价与没做的事

1. **保存钮在页脚不在导航条。** 导航条那一格由 `NavScreen.trailing` 给，而它在表单组件
   外面渲染——要让它读得到 `canSave/busy`，得给 NavStack 加一层「每页自己的 provider」。
   那是个说得通但更大的改动，这次没做。
2. **行尾动作还是常驻的文字钮**（撤回 / 删除 / 移出），不是左划露出。左划那套的物理层
   已经在 `lib/spring.ts` 里（demo 里跑通过），接到列表上是独立一件事。
3. **换一格两次点击**（决策 1 的代价）。
4. **几何没写成断言**（同 ADR-0236 第 1 条）：分隔线内缩、行高、大标题收起那 26px 全是
   紧挨代码的注释，扫源码的正则会在任何无害重构上翻红。
5. **真机一次都没跑过。** 门禁全绿、`npm run build` 过，但这一版的绝对定位页栈装在
   `DrawerContent` 里的真实表现（滚动、手势、材质）没在 GUI 上验过。在 worktree 里起
   Electron 撞到一个环境问题：`npm run build` 把 renderer 产物写去了**主 checkout 的**
   `out/renderer`，worktree 只有 `out/main`+`out/preload`，于是 Electron 起来即退。
6. **`weekLimitMicro` 要部署 edge 才生效**。部署前客户端拿不到分母，界面走决策 7 的退路
   （按工作区合计算 + 组尾说明换了口径），不会报错也不会回落到 credit。
