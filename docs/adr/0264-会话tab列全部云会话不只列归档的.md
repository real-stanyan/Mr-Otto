# ADR-0264：工作区设置页「会话」tab 列全部云会话，不只列归档的

- 日期：2026-09-08
- 状态：已接受
- 关联：issue #1115；推翻 ADR-0199 Task 13 / #919 在这一页上的取舍；沿用 ADR-0217 的理由但重判代价；判据同 ADR-0251（#1056）、ADR-0243/0197（读不到 ≠ 空的）

## 背景

真机上 `mandy's bubble tea` 这个工作区有 2 条云会话（真库 `workspace_sessions` 两行，`kind='cloud'`、`archived=false`），侧栏「团队」那一栏两行都在。点 ⚙ 落地的第一格「会话」tab 却一个字都不提它们，屏幕上只有一句「还没有人发布会话到这个工作区。」——那句话说的是 `kind='package'`，跟云会话完全是另一样东西。

机制是两处严格互补的判据，读的是同一份 `cloudSessionList[ws.id]`：

- `WorkspacesSidebarSection.tsx` `.filter((r) => !r.archived)`
- `WorkspacePage.tsx` `.filter((r) => r.archived)`，且 `if (rows.length === 0) return null`

原实现的头注写了理由：「活着的那些在侧栏工作区组里，新建也在那儿——这里只是归档的去处」，依据是 ADR-0217 那条「入口留两个只会让人以为它们是两样东西」。

## 决策

**这一 tab 列出这个工作区的全部云会话**，进行中的一节在上、已归档的一节在下。

## 理由

那条理由**成立，但代价没付**。这一 tab 叫「会话」，还是 ⚙ 的落地页；「没有第二个入口」这个好处，是拿「最常见的情形下这一屏是空白」换来的。同一个判据维护者在 #1056 已经下过一次——一个叫「文件」却一个文件都列不出来的页面是 #722 撒谎的勾的近亲；那次的修法不是补文案，是让页面对得起它的名字。

重复的代价用**分工**抵掉，不是靠把两份清单摆成两个功能：

| | 有哪些 | 归档 / 删除 |
|---|---|---|
| 进行中 | 这一页 **和** 侧栏 | 只在侧栏那颗 ⋮ |
| 已归档 | 只在这一页 | 只在这一页那颗 🗑（ADR-0245：最想清掉的那批根本不在侧栏里） |

所以 ADR-0217 真正防的东西还在：**动作只有一个入口**，两处并列的只是「有哪些」这个只读的答案。

## 顺带收掉的一条：读不到 ≠ 一条都没有

改动之前，云会话那一节为空时整节 `return null`，「空」不承载任何断言，所以「拉不到」与「一条都没有」长得一样也没有后果。改完之后空态是一句真话（「这个工作区还没有进行中的云会话」），于是必须把这两件事分开——这正是 ADR-0243、ADR-0251 反复钉的那条。

判据不新增 store 状态：

- `refreshCloudSessions` 失败时只写 `workspaceGroupsError`、**不动** `cloudSessionList`（这是对的：「拿不到」≠「被清空」，同 ADR-0197 grants 缓存的规矩，一次抖动不该把上一份清单抹掉）
- 所以「这一趟拉完了没有」+「拉完之后这一格有没有值」就是完整的三态：`loaded && list === undefined` 只可能是失败
- **第一帧什么都不画**，不是画一句空态——那一瞬间还没有任何证据

## 顺带收掉的第二条：一份都没发布过时，「已发布会话」整节不出

这一 tab 上还有另一节 —— 「已发布会话」，说的是 `kind='package'`：本机某条会话的一次性快照包，从会话头部「更多」→「发布到工作区…」放上来，全体成员（含未来加入者）可以反复导入 fork 成自己机器上的新会话（ADR-0198 切片 3）。它跟云会话是两样东西。

它原来在空的时候画一句「还没有人发布会话到这个工作区。」，**与紧邻的归档那一节自己写着的规矩直接矛盾**（「一条归档的都没有时整节不出——这一页是管理面，不该为一件没发生过的事留一行空态」）。真机上的后果是：一个没发布过、没归档过的工作区，这一 tab 的**唯一内容**是一句与它无关的话，而它真有的那两条云会话一个字都不提。

现在照归档那条办：`rows.length > 0` 才画。能这么收的前提是云会话那节已经常驻且自带空态——这一页不会整个空掉；发布的入口本来也不在这一页。

## 已知代价

1. **同一条会话在两处列得出来**（侧栏 + 这一页）。这是 ADR-0217 当初想避开的形态，这次是明知代价选的；把它压住的是上面那张分工表——只要动作不跟着复制，两处就还是「同一个东西的两个视图」而不是「两个功能」。
2. **这一节仍然没有推送通道**（`workspaceCloudList` 无 `onChanged`），挂载时拉一次。别人在别的机器上归档/新建，这一页是陈旧的，直到重新进这一页。与改动前一样，不是本条引入的。
3. **进行中那几行没有归档/删除**。想清掉一条活着的，仍然要回侧栏那颗 ⋮。这是决策的一半（动作单一入口），不是漏做。
4. 空态那句话点名了「侧栏「团队」里那颗 ＋」——**文案里写死了另一处 UI 的位置**。侧栏那一栏改名过一次（工作区→团队，#1087），改名时这句话不会报错，只会开始指错地方。
