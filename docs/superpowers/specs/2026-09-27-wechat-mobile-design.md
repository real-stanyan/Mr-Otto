# 手机端改成微信式布局 —— 设计

- 日期：2026-09-27
- Task issue：#1386（demo 已过；桌面那一半另做）
- 上游：demo `.demo/wechat/mobile.src.html`（分支 `claude/mr-otto-redesign-b461e2`，artifact
  https://claude.ai/artifact/N3zSH1ZR284ZxDAYgQafTa）
- 关系：推翻 ADR-0317 决定 1 的「没有底栏、没有第二个根」（ADR-0322）；#1356 那一版的判据
  （谁排前面、藏哪些事件、派活线、先开口、语音编排）原样留着，换的是外壳

维护者原话：「按照设计稿做手机版，一口气全做完。」设计稿是那份可点的 demo；demo 里每一处
与今天后端对不上的地方，下面 §3 逐条说清怎么落。

## 0. 位置

手机端仍是云端那一半的客户端（ADR-0317 决定 5）：智能体跑在个人主场里，桌面和手机是同一条
云会话的两个客户端。这一版多接了两样**后端早就有、手机上从来没有**的东西：

- **朋友**：`friendships` / `messages` 两张表（0001）+ RLS + realtime。#1356 之前手机上有过
  （`mobile/src/friendsApi.ts`，a8145959 删掉），查询层照搬回来。
- **有真人的群**：团队（`workspaces.kind='team'`）里的每一条云会话。手机从没开过团队会话；
  协议、客户端、时间线判据都是同一份。

## 1. 已验前提

1. `messages` 收发、`friendships` 加 / 接受 / 删、`profiles` 按名字邮箱搜：RLS 已经收在当事
   双方（`supabase/migrations/0001_friends.sql`），桌面天天在用（`src/main/supabaseFriendsApi.ts`）。
2. 改名字 / 头像 = `profiles` 本人那一行（`profiles_update_self`）；0007 已经让登录不再覆盖
   自定义头像。头像是 data URL，上限 `AVATAR_MAX_CHARS`（128 KB）。
3. 改密码 = `auth.updateUser({password})`；「现在的密码」对不对用 `signInWithPassword` 验
   （换来的是同一个人的新 session）；忘了走 recovery OTP（8 位，ADR-0194），闸门那一套现成。
4. 团队清单 `listWorkspaces`（RLS：owner 或成员）、团队快照 `fetchWorkspace`、团队里的云会话
   `listCloudSessions` / `fetchCloudLasts`、点名收件箱 `listMentions`：`src/shared/supabaseWorkspacesApi.ts`
   全有，手机能直接 import。
5. 团队会话里有审批（`sandbox_approval` 缺省 `ask`）。审批请求本身是日志事件
   （`approval_request` 带 `argsFields` / `expiresTs` / `initiatorUid`），批与拒走现成的
   `cloudClient.approve`。**不接审批就开团队会话 = 手机上发的每一句需要动手的话都卡死十分钟**，
   所以审批卡是这一版的一部分。
6. 按住说话：原生模块的 `pause()` 会把手上那半句收成一条 `final` 再报 `paused`（`Recognizer.swift`），
   松手先 pause 再 stop 就拿得到整句——**不改 Swift**（改了要重编开发版、要人重新点授权）。
   只在开发版里有（同电话钮，ADR-0320）。

## 2. 边界：这一版不做的

- **不改后端、不跑库、不部署。** 下面这件因此做不到，界面上不画：
- **新建「你的智能体 + 朋友」混在一起的群。** demo 画了，NEW_THINGS 那一栏也写明了要改后端
  （智能体跟着群主进群、额度记群主头上、旧团队每条会话变成一个群）。今天你的智能体只住在个人
  主场里，朋友不是主场的成员；把朋友加进主场 = 让他们碰得到你的文件、记忆、连接器——那是产品
  与安全的决定，不该在「做手机版」里顺手做掉。所以：「发起群聊」只挑智能体（主场群聊，A3 现成）；
  朋友资料页没有「拉进群聊」；朋友私聊的 ⊕ 里没有「拉人建群」。**留给维护者拍板**（§9 第 1 条）。
- 团队群的成员管理（拉人 / 踢人 / 退出 / 解散）不在手机上做：团队一个就是一整套（成员、连接器、
  几条会话共用），在手机上拉一个人进「这个群」其实是拉进整个团队。信息页照实写「成员由群主在
  电脑上管」。
- 推送通知、「有人 @ 我时通知」那两行开关：手机没有推送凭据（ADR-0256 已知代价），demo 的
  设置页那两行不画。
- 额度的真规矩不动（维护者 2026-09-27「先只改设计」）：见 §5.9。

## 3. 与 demo 对不上的地方（实现以这里为准）

1. **未读数**：只有朋友私聊能数出条数（`messages` 在本机按 id 比已读游标）；智能体私聊 / 群 /
   团队群的库里只有「最后一句」一格（`last_ts` / `last_from`，0040），数不出条数（#1282）。所以
   这几种画一枚**点**（有新的、不是我说的、晚于我上次看过），朋友私聊画数字。底栏「聊天」角标与
   标题「聊天(n)」数的是**有新消息的聊天有几条**，不是消息条数——一个数两种口径最坏，
   选一个说得清的。已读游标存在这台手机上（kv-store，按账号分键）；第一次装上时把每条的「最后
   一句」当成看过（否则一装上满屏都是未读）。
2. **「[有人@我]」**：只有团队群里有人会 @ 我（`workspace_mentions`，ADR-0256）。进房 = 已读
   （照桌面）。
3. **头部「正在输入 / 正在干活」**：从这一条的日志 + 流式碎片推（`nowRowOf`）：作答中 =
   「正在输入…」、执行中 =「正在干活…」、排队中 =「排队中…」。只有开着的这一条知道；列表行上不画
   （同 #1282）。
4. **「此刻」那一行**：demo 画成对方那边一个打字的气泡。照画，但**「停」留着**（ADR-0227 的能力，
   demo 没画不等于不要）：气泡右边一颗小的「停」，只在它真在跑时出现（`stopButtonRows`）。
5. **按住说话发出去的是普通一句话**，不带 `voice` 记号：那个记号的意思是「通话里说的」，带上它
   会被折进通话卡（ADR-0288）。demo 气泡上那枚小话筒因此不画——没有数据说「这句是说出来的」。
6. **时间线的时间**：demo 按「隔 5 分钟插一条」写时刻（今天写钟点，别的日子带日子），替掉 #1356
   那种每个自然日一条分隔 + 每一段一个「名字 · 时间」。
7. **智能体一条回复拆成几个气泡**（ADR-0266，空行 = 下一条）：头像只画在第一个气泡旁，后面几个
   对齐缩进——一次说的几段读成一口气说的，不是几次。
8. **新建智能体**是居中弹窗（demo 定的；表单用居中弹窗是既有规矩）。#1356 那张 70% 抽屉退役；
   「走一遍它干活的样子」那张大脸换成弹窗里一张会动的小脸。
9. **换个形象 / 说话的声音 / 换头像**是在几样里挑一样，仍是底部抽屉（维护者：选择器照旧）。
   demo 把「换个形象」画成了居中弹窗，按规矩改回抽屉。
10. **团队群的标题** = 那条会话的标题（runtime 自动起的名，ADR-0283），没有时退回团队名。
11. **别人的智能体**（团队群里的）：资料页只读——名字、「X 的智能体」、职责、在的群；不能私聊、
    不能改（demo 同款）。
12. **「应用」页没有状态点**：连不连得上只活在桌面内存里（#1376，A5 已判），demo 那几个绿点不画。
13. **Free**：没有主场（没订阅 / 档位不带）时，聊天页顶上一张订阅卡、通讯录「智能体」段里一张；
    朋友私聊、团队群照常能聊（demo 同款）。有主场就不再看档位（降了档的人聊天记录还在，同 A1）。

## 4. 导航与外壳

- 一个原生栈（ADR-0293 决定 2 / ADR-0317 的原生栈原样成立），栈底是一个**页签**屏：聊天 /
  通讯录 / 我（`@react-navigation/bottom-tabs`，依赖早就装着）。推进来的页盖住底栏（照 iOS 微信）。
- 底栏自己画：半透明毛玻璃（`expo-blur`）、上沿一道细线、当前那格点缀色、角标是点缀色不是红
  （DESIGN.md：颜色只用来说「出事了」）。
- 页签根的页头自己画（标题居中 + 右边一颗）；推进来的页用原生导航条：只留返回箭头（有别的未读时
  箭头后面带数字）、标题居中、右边一颗。
- 列表语汇换成微信的通栏：整行铺满、分隔线从头像 / 文字右边开始、段头段尾小字。`ui.tsx` 的
  `Group` / `Row` / `Page` 跟着改，于是 A5 那几页（文件、应用、记忆、用量、订阅、设置）一起换。
- 头像：智能体 = 像素脸画在圆角方块里（纸白底，两个主题同值，照 demo 的 63 格构图）；人 = 头像图
  或名字首字；我 = 头像图或首字（反色底）；群 = 九宫格拼图。

## 5. 屏幕

### 5.1 聊天（页签）
标题「聊天(n)」+ 右上 ⊕（新建智能体 / 发起群聊 / 添加朋友；没有主场时只剩添加朋友）；搜索条；
没有主场时一张订阅卡；一列会话：智能体私聊（聊过的）、智能体群、团队群、朋友私聊（有过消息的），
按最近一句降序。一行：头像 48 + 未读角标 / 名字 / 时间 / 第二行（草稿 >「[有人@我]」> 最后一句，群里
带「名字：」）。搜索按名字与最后一句过滤。

### 5.2 聊天页
- 原生导航条：标题（群带人数）+ 第二行状态（§3.3）；右边「···」进聊天信息；返回键带别的未读。
- 时间线：倒置列表；我在右、别人在左带头像（群里头像上方写名字）；旁白、派活线、名单变更、接力线
  是居中的一枚灰底小条；通话：私聊是一个「通话时长」气泡、群里是一行居中可点的小条，点开是通话全文
  （现成的 CallSheet）。先开口的六句现成话照旧挂在它那句开场白底下。
- 审批卡（团队群）：谁要做什么（`approvalCardTitle` + 逐字段），只有发起这一轮的人或群主看得到
  「拒绝 / 允许」，别人看到「等 X 批」；过期、批完之后收成一行小字。
- 输入栏：左「按住说话 ⇄ 键盘」（只在开发版里有）、中间输入框 / 按住说话、右 表情 + ⊕（打了字 ⊕
  变「发送」）。⊕ 面板：语音通话、拉人建群（私聊）、拉人（主场群）、@ 谁（群）。群里打一个「@」
  直接弹选人抽屉。表情面板往输入框里插字。
- 通话：点「语音通话」整屏升起（脸、名字、计时、在听 / 正在说、转文字、静音、挂断）；左上「收起」
  回到聊天页，头部下面留一颗「通话中 00:12」的胶囊，点它回来。离开这一页 = 这台停听、通话还在
  （A4 原样）。

### 5.3 聊天信息
私聊：它的头像 +「建群」；它的资料那几行（同智能体资料页）；删除这只（管理员没有）。
主场群：成员格（我 + 智能体）+ 拉人 + 移出；群聊名称（改）；群主（我）；没 @ 谁的时候；解散。
团队群：成员格（人 + 智能体，只看）；群聊名称（只看）；群主；注脚「成员与智能体由群主在电脑上管」。
朋友私聊：朋友头像；邮箱；删除朋友。

### 5.4 通讯录（页签）
标题「通讯录」+ 右上「添加朋友」；搜索；「新的朋友」（带待处理数）、「群聊」（带个数）；可折叠的
「智能体」（段头右边「新建」）与「朋友」两段（折叠状态记在这台手机上，搜索时一律展开）；底部
「N 只智能体 · M 位朋友」。

### 5.5 智能体资料
大头像 + 名字 +「智能体」标签 + 职责；形象 / 名字 / 职责 / 还有什么要交代的 / 说话的声音 /
本周用了额度的（「说话的声音」随 #1388 的挑声音进来，那边合进来之前这一行不画）；「发消息」「语音通话」。名字、职责、交代走居中弹窗、存了就生效（A1 的校验与查重名
原样）。

### 5.6 朋友 / 新的朋友 / 群聊
朋友：头像、名字、邮箱、一起在的群、发消息、删除朋友。新的朋友：别人加我的（接受 / 拒绝）、我加
别人的（等对方同意 / 撤回）。添加朋友：居中弹窗，按名字或邮箱搜、点一个发申请。群聊：所有群一列
+ 右上新建。

### 5.7 朋友私聊
同一套气泡与输入栏（没有 ⊕ 面板里的那几样、没有按住说话以外的差别）；一次拉最近 50 条，往上翻
再拉；realtime 推新消息，通道哑了降级成轮询（ADR-0027 的手机版，#1356 之前那份原样）。

### 5.8 我（页签）
头部（头像、名字 + 档位、邮箱）→ 个人信息；「订阅与额度」（右边写本周还剩百分之几）；「它们共用的一台
电脑」一段：文件 / 应用 / 记忆 / 这周谁用得多（A5 那几页）；设置（外观、连接诊断、版本、退出登录）。

个人信息：头像（抽屉：从相册选一张 / 换回名字的首字）、名字（居中弹窗）、邮箱（只看）、改密码
（居中弹窗：现在的、新的、再输一遍；忘了 → 邮箱验证码重设）。

### 5.9 订阅与额度
demo 只画「本周」一格。真规矩里 5 小时那扇窗还在（维护者「先只改设计」），所以：主格画本周；
**5 小时那扇窗此刻比本周更紧、且已经到了要提醒的程度（告急 / 用完）时，底下多一行实话**
（「这 5 小时用得快，X 后恢复」）。不画的话，人会对着「本周还剩 81%」被拦住而不知道为什么。
下面当前档位 + 订阅 / 换档（A5 那一页）。

## 6. 数据层（手机端）

- `homeStore`（现成）：主场快照 + 聊天清单 + 最后一句。
- `teamsStore`（新）：`listWorkspaces` 去掉主场 → 每个团队 `fetchWorkspace` + `listCloudSessions`
  + `fetchCloudLasts`；外加 `listMentions`。跟着聊天页签的刷新时机走（进前台、回到列表），不轮询。
- `friendsStore`（新）：好友快照 + 每位朋友最后一条 + 未读（本机游标）；realtime 两条通道，
  哑了轮询。
- `inboxSeen`（新）：已读游标（kv-store，按账号分键）+ 草稿（内存）。
- 列表怎么拼、怎么排、角标怎么数、时间怎么写：纯函数进 `src/shared/wechatInbox.ts`，跟着根门禁跑。

## 7. 挪进 `src/shared/` 的

- `src/main/userProfile.ts` 的纯逻辑（名字收敛、头像校验、列补丁、行转换）→ `src/shared/profileEdit.ts`，
  桌面改 import、行为不变；改密码的两句判据（demo 的 `passwordProblem` / `passwordReady`）一起放。

## 8. 实现顺序

S1 纯逻辑 + 测试 → S2 外壳（页签、底栏、通栏列表）→ S3 聊天页 → S4 智能体资料 / 聊天信息 / 新建
→ S5 朋友 → S6 团队群（含审批卡）→ S7 我 / 个人信息 / 额度 → S8 通话整屏 + 按住说话 →
S9 未读与草稿 → S10 文档、模拟器冒烟。每片一个提交，门禁绿再往下。

## 9. 留给维护者拍板

1. 要不要改后端，让「你的智能体 + 朋友」能在同一个群（§2）。
2. 额度真规矩要不要去掉 5 小时（§5.9；桌面、网关、价目、接力刹车都要跟）。
3. 桌面那一半（#1386 的另一半，含「撤掉写代码」要删还是先藏）。

## 10. 已知代价

1. 未读只有朋友私聊是准的条数，其余是一枚点；换一台手机已读游标不跟过去。
2. 团队群只能聊、批、看，管不了成员（§2）。
3. 按住说话、语音通话只在开发版里有（ADR-0320）。
4. `Group` / `Row` 换成通栏，A5 那几页的样子一起变了（维护者要的是整套一致）。
5. 手机端第一次开团队会话，审批卡是新写的——桌面那张卡的几条纪律（逐字段、谁能批）照抄，
   真机没跑过。
6. 真机一次没跑过；登录之后的流程 agent 跑不了（要人输密码），用临时根组件 + 假数据在模拟器上过
   （iPhone 17 Pro，浅色、深色各一遍；冒烟台不提交）。冒烟撞见并修掉的：选完动作单 / ⊕ 菜单之后
   相册、弹窗不出来（iOS 不许在正在退场的 Modal 上再叠一个，改成等 `onDismiss`）；未读点画成圆角方块；
   键盘起着时输入栏和键盘之间空一道。
7. 形象陈列馆的入口从名册右上搬到设置页底下（只在开发构建里有）。
