## 0. 位置与开关

三栏：竖条 64（我 / 聊天 / 通讯录）· 列表 280 · 主区。窗口窄于 1000 时列表收到 240、窄于 760 时 216；
窄于 560 才退成一栏（列表与主区轮流占满，头部多一颗返回）。

**写代码那一半的入口全部藏起来，代码一行不删**。开关是环境变量 `OTTO_CODING=1`：主进程读，随 `boot()` 下发
（`BootInfo.codingUi`，可选字段，旧渲染层不认识也照旧）。开着时 `App()` 原样画旧界面（任务 / 项目 / 团队三栏、
本机会话、Files、终端……），维护者自己还要用、e2e 还要跑（`tests/e2e/harness.ts` 默认带上它）。关着（默认）时
`App()` 过了登录那道闸之后只画新的 `WxApp`。

藏的是**入口**，不是能力：主进程照旧装配本机会话那一套（岛、托盘、后台任务都还在，只是没人从界面上起本机会话）。
删掉它们是另一条 issue 的事（删之前要先想清楚 e2e 与维护者自己的用法怎么办）。

## 2. 缺的数据（主进程补三条 IPC，渲染层补四格状态）

1. `workspaceCloudLasts(workspaceId)` → 那个 workspace 里每条云会话的「最后一句」（`fetchCloudLasts`，0040 那三列；
   读不到回空，列表退回按 `updated_at` 排、第二行空着）。
2. `workspaceGuestChats()` → 别人主场里拉我进去的群（`listGuestChats`，0043）。
3. `friendsRecentMessages()` → 我收发过的最近 300 条私信（RLS 已收在收发双方），列表每位朋友那一行的最后一条与
   未读条数从它算（`friendThreads`）。
4. `workspaceCloudList` 的类型收成 `CloudSessionRow[]`：主进程本来就把 `humans` 那一格带上来了，只是类型把它藏了。

刷新时机：开机、窗口重新聚焦、回到「聊天」那一栏、自己改了东西之后，**外加窗口看得见时每分钟一次**。这一条与手机不同：
桌面窗口一开就是一整天、一直聚焦着，「重新聚焦」这个信号一天可能一次都不来——只靠它，别的群里来了新话列表一整天不动。
一次刷新是每个 workspace 两条小查询；窗口看不见（切走、最小化）时不打。朋友私信另有 realtime 那条路，不靠这个。
这一趟没读到的一格留着上一次的（「读不到」不许说成「没有」）。

## 3. 栏目

### 3.1 竖条
我的头像（点开「我」）、聊天（角标 = 有新消息的聊天有几条，同手机）、通讯录（角标 = 别人加我、还没处理的申请数）。
macOS 的红绿灯压在竖条顶上（竖条上沿留 48px 给它），整条竖条与列表头、主区头是拖窗口的地方（`app-region: drag`，
按钮一律 `no-drag`）。

### 3.2 聊天
列表头：搜索框 + ⊕（新建智能体 / 发起群聊 / 添加朋友；没订阅时只有「添加朋友」）。没订阅时列表顶上一张卡劝订阅，
朋友拉我进的群照常列。点一行 = 主区打开这条聊天；私聊还没建（从通讯录点「发消息」进来）时是草稿，第一句发出去才建
（`openAgentChat` 原样）。

### 3.3 通讯录
新的朋友（带数）· 群聊（带数）· 智能体（可折叠，头上一颗 ＋）· 朋友（可折叠）。主区：
- 智能体资料页：名字 / 职责 / 形象 / 还有什么要交代的，每行点开就改；说话的声音**只读**（ADR-0322 决定 6：
  桌面照读、不给挑）；型号与应用在「更多设置」里（原来那扇 `AgentSettingsDrawer`，不抄第二份）；「发消息」「拉进群聊」。
  管理员删不掉，别的在最底下一行红字删除。别人的智能体（团队里的、朋友群里的）只能看。
- 朋友资料页：一起在的群、「发消息」「拉进群聊」。
- 新的朋友：别人加我的申请（接受 / 忽略）+ 右上「添加朋友」。
- 群聊：主场的群 + 团队群 + 别人拉我进的群，「发起群聊」。

### 3.4 我
头像 + 名字 + 档位 · 订阅与额度（只报本周那一格，#1392）· 它们共用的一台电脑：文件 / 应用 / 记忆 / 这周谁用得多 ·
设置（外观、检查更新与版本）· 退出登录（二次确认）。

主区每一格都是一个铺满的 `NavStack`：「应用」里的添加主机、「记忆」里的编辑页是**推进来**的二级页——那几格是为团队设置的
推入式导航写的，`useNav()` 离了 `NavStack` 直接抛错（冒烟时点「应用」整页白屏，就是这么发现的）。为此 `NavStack` 多两个开关：
`dragBar`（导航条同时是拖窗口的地方——它贴着窗口上沿）、`contentClassName`（正文收成居中的一列，不然二级页的输入框会被
拉到一千像素宽）。二级页的返回写「应用」不写「连接器」（`WorkspaceConnectorsTab` 的 `backLabel`）。
个人信息那张卡不再画第二颗「退出登录」（`ProfileCard` 的 `signOut={false}`）：列表最后一行就是它。

### 3.5 聊天主区（`CloudSessionPage` 的 `wx` 外观）
- 头部 58px：标题（群带人数）+ 此刻在干什么（正在输入 / 正在干活 / 排队中）· 语音通话钮（判据原样）· ···（聊天信息抽屉）。
- 时间线：头像 36px 方圆角；群里别人说的话上面写名字，私聊不写；时刻不再逐条写，隔 5 分钟以上插一条居中的时刻（`needsTimeRow`，同手机）。
- 输入框：一块平的面板（上边一道线），左下表情 / @，右下「发送」，Enter 发送、Shift+Enter 换行。团队群的「免审批」开关留在这一行（ADR-0243：刹车要在手边）。
  「读不到免审批」那句警示**只对团队会话说**：主场一次都不查那一列（ADR-0298 / 0325），客人那一侧拼出来的快照那一格恒为 null，
  照判就是对客人说一句假话（旧界面也有这个洞，一起修了）。
- 审批卡：主场群里只有群主批得了（ADR-0325），等谁批那一行写群主；团队群照旧「发起人或所有者」。
- 聊天信息抽屉（右侧 340px）：私聊 = 这只的资料格 + 「建群」；群 = 成员格子（人 + 智能体）+ 拉人 / 移出（群主）+ 群名 + 解散 / 退出；团队群 = 成员 + 去团队设置。

### 3.6 朋友私聊
同一张微信皮：头部名字、时间线、输入框。消息来源、乐观上屏、翻旧页都是现有那条路。
